靜力平衡 18：碗內三球堆疊平衡分析

三球系統整體平衡求碗壁支持力・頂層球隔離法・底層球正交平衡推導

📖

題目內容

聯考與分科測驗壓軸經典題

如圖所示，將三個半徑皆為 $R$、重量皆為 $W$ 的相同小球 $A$、$B$、$C$ 靜置於半徑為 $3R$ 的光滑大碗內。已知頂部 $C$ 球之球心恰好位在大碗之圓心處，且三球球心連線構成一正三角形。試求：
(1) $B$、$C$ 兩球間之相互作用力為多少？
(2) $A$、$B$ 兩球間之相互作用力為多少？
(3) $A$ 球作用於碗壁之力為多少？

🏛️ 解法一【整體法＋隔離法】口訣：先包成整體消內力，再拆單球求推力！
• 整體系統（A+B+C）：內部的互推力全部抵消，總重 $3W$，兩側碗壁對稱支撐，鉛直列式 $2N_B \cos 30^\circ = 3W \implies \mathbf{N_B = \sqrt{3}W}$（秒解第 3 小題）。
• 隔離頂球 C：受重力 $W$ 及底層兩球斜向支持，鉛直列式 $2F_{BC} \cos 30^\circ = W \implies \mathbf{F_{BC} = \frac{\sqrt{3}}{3}W}$（秒解第 1 小題）。
• 隔離底球 B：受到四個力，水平列式 $F_{AB} = (N_B - F_{BC})\sin 30^\circ \implies \mathbf{F_{AB} = \frac{\sqrt{3}}{3}W}$（秒解第 2 小題）。
🎯 解法二【頂球拉密＋底球共線直角三角形】：幾何視覺秒殺流！
• 頂球 C 剛好三力共點：兩支持力夾角 $60^\circ$（對面是重力 $W$），與重力各夾 $150^\circ$。套拉密定理： $\frac{W}{\sin 60^\circ} = \frac{F_{BC}}{\sin 150^\circ} \implies \mathbf{F_{BC} = \frac{W}{\sqrt{3}}}$！
• 底球 B 四力變三力的絕技（反向共線）：碗壁力 $N_B(\nwarrow)$ 與頂球壓力 $F_{BC}(\searrow)$ 在同一條通過 C 的直線上，合成為淨力 $F_{\text{net}} = N_B - F_{BC}$。
• 首尾相接直角三角形：$W(\downarrow) \to F_{AB}(\rightarrow) \to F_{\text{net}}(\nwarrow)$，邊長比為 $1 : \sqrt{3} : 2$： $\mathbf{F_{AB} = W \tan 30^\circ = \frac{W}{\sqrt{3}}}$，$\mathbf{N_B = F_{\text{net}} + F_{BC} = \sqrt{3}W}$！

依據受力平衡分析，三道小題之答案依序為何？

幾何分析

球心幾何特徵與正三角形構成

大碗半徑為 $3R$，各小球半徑為 $R$。
頂層球 $C$ 之球心恰為碗心，因此由碗心至 $A$、$B$ 兩球球心之距離均為 $3R - R = 2R$。
而兩兩小球接觸，球心間距皆為 $R + R = 2R$。
因此 $\triangle ABC$ 為邊長 $2R$ 的正三角形，三邊與鉛垂線之夾角均為 $30^\circ$。

步驟 1

整體法求碗壁對球之支持力（求解第 3 小題）

以三球整體 $(A+B+C)$ 為系統，總重量為 $3W$。
系統僅受兩側碗壁的支持力 $N_A$ 與 $N_B$ 向上支撐。由於支持力通過球心與碗心，方向與鉛垂線夾角均為 $30^\circ$： $$N_A \cos 30^\circ + N_B \cos 30^\circ = 3W$$ 由左右對稱性 $N_A = N_B$： $$2 N_A \left(\frac{\sqrt{3}}{2}\right) = 3W \implies N_A = N_B = \sqrt{3}W$$ 由牛頓第三定律，球作用於碗壁之力亦為 $\sqrt{3}W$。

步驟 2

隔離頂層 C 球求球間作用力 $F_{BC}$（求解第 1 小題）

$C$ 球受自身重力 $W$ 鉛直向下，以及底層兩球對其之支持力 $F_{AC}$ 與 $F_{BC}$。
由對稱性 $F_{AC} = F_{BC}$，兩力與鉛垂線夾角皆為 $30^\circ$： $$2 F_{BC} \cos 30^\circ = W \implies 2 F_{BC} \left(\frac{\sqrt{3}}{2}\right) = W$$ 解得： $$F_{BC} = \frac{W}{\sqrt{3}} = \frac{\sqrt{3}}{3}W$$

步驟 3

隔離底層 B 球求水平互推力 $F_{AB}$（求解第 2 小題）

$B$ 球受到四個力作用：

  • 碗壁支持力 $N_B = \sqrt{3}W$（斜向左上，與鉛垂線夾 $30^\circ$）。
  • $C$ 球推力 $F_{BC} = \frac{\sqrt{3}}{3}W$（斜向右下，與鉛垂線夾 $30^\circ$）。
  • 重力 $W$（鉛直向下）。
  • $A$ 球對 $B$ 球之水平推力 $F_{AB}$（水平向右）。

注意：$N_B$ 與 $F_{BC}$ 剛好在同一直線上且方向相反！
列水平方向合力為零： $$F_{AB} = (N_B - F_{BC})\sin 30^\circ$$ 代入已知量： $$F_{AB} = \left(\sqrt{3}W - \frac{\sqrt{3}}{3}W\right) \times \frac{1}{2} = \left(\frac{2\sqrt{3}}{3}W\right) \times \frac{1}{2} = \frac{\sqrt{3}}{3}W$$

另解技巧

解法二：頂球拉密定理 ＋ 底球共線力直角三角形

① 頂球 C（三力共點，拉密定理秒殺）：
受重力 $W(\downarrow)$ 與底層兩球支持力 $F_{AC}(\nearrow)$、$F_{BC}(\nwarrow)$。
$F_{AC}$ 與 $F_{BC}$ 夾角為 $60^\circ$（對應 $W$）；各自與 $W$ 夾角為 $150^\circ$。
代入拉密定理： $$\frac{W}{\sin 60^\circ} = \frac{F_{BC}}{\sin 150^\circ} \implies F_{BC} = W \cdot \frac{1/2}{\sqrt{3}/2} = \frac{\sqrt{3}}{3}W$$

② 底球 B（四力變三力：共線力直角三角形）：
底球 $B$ 受四個力：重力 $W(\downarrow)$、頂球推力 $F_{BC}(\searrow)$、碗壁支持力 $N_B(\nwarrow)$、水平推力 $F_{AB}(\rightarrow)$。
關鍵觀察：$N_B$ 與 $F_{BC}$ 共線且反向（均沿連心線方向，與鉛直夾 $30^\circ$）！
將兩者合成為一個沿此斜線的淨力 $F_{\text{net}} = N_B - F_{BC}(\nwarrow)$。
此時底球等效為受三個力：$W(\downarrow)$、$F_{AB}(\rightarrow)$、$F_{\text{net}}(\nwarrow)$，恰構成一個 $30^\circ-60^\circ-90^\circ$ 直角三角形！
$$F_{AB} = W \tan 30^\circ = \frac{\sqrt{3}}{3}W$$ $$F_{\text{net}} = \frac{W}{\cos 30^\circ} = \frac{2\sqrt{3}}{3}W \implies N_B = F_{\text{net}} + F_{BC} = \frac{2\sqrt{3}}{3}W + \frac{\sqrt{3}}{3}W = \sqrt{3}W$$

結論： 本題正確答案為 (A) (1) $\frac{\sqrt{3}}{3}W$；(2) $\frac{\sqrt{3}}{3}W$；(3) $\sqrt{3}W$。
