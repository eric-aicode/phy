(1) 沿斜面向上施力 $F_1$ 時：

取斜面上重量為 $W$ 之物體為隔離體，建立垂直斜面方向之靜力平衡方程式：

$$\Sigma F_{\perp} = 0 \implies N_1 - W\cos\theta = 0$$
答：斜面施於物體之作用力（正向支持力）為 $N_1 = W\cos\theta$
(2) 沿水平方向施力 $F_2$ 時：

物體受重力 $W$（鉛直向下）、外力 $F_2$（水平向右）及斜面支持力 $N_2$（垂直斜面向上，與鉛垂線夾角亦為 $\theta$）。
建立鉛直方向之靜力平衡方程式：

$$\Sigma F_y = 0 \implies N_2\cos\theta - W = 0$$
答：斜面施於物體之作用力為 $N_2 = \dfrac{W}{\cos\theta} = W\sec\theta$
觀念深究 (1)

沿斜面向上施力（經典斜面坐標系分解）

物體置於光滑斜面上，斜面施於物體的作用力即為正向支持力 $N_1$（方向垂直斜面向上）。

當施加沿斜面向上的外力 $F_1$ 時：

  • 外力 $F_1$ 完全沿斜面方向，其垂直斜面的分力為 $0$。
  • 將重力 $W$ 分解為：
    • 平行斜面向下分力：$W_{\parallel} = W\sin\theta$
    • 垂直斜面向下分力：$W_{\perp} = W\cos\theta$
  • 垂直斜面方向受力平衡： $$N_1 = W_{\perp} = W\cos\theta$$
  • （附帶平衡關係：平行斜面方向 $F_1 = W\sin\theta$）
(1) 斜面施於物體的作用力為：$N_1 = W \cos\theta$
第 (2) 小題

沿水平方向施力（鉛直水平坐標系分解或直角封閉三角形）

當施加水平方向的外力 $F_2$（水平向右推向斜面）時：

物體受三個力：鉛直向下的重力 $W$、水平向右的推力 $F_2$、垂直斜面向左上方的正向力 $N_2$。
正向力 $N_2$ 與鉛垂線的夾角恰好等於斜角 $\theta$！

  • 方法一：鉛直方向力平衡
    外力 $F_2$ 為水平力，在鉛直方向無分力。因此鉛直向上只有 $N_2$ 的垂直分量： $$\Sigma F_y = 0 \implies N_2 \cos\theta = W \implies N_2 = \frac{W}{\cos\theta} = W\sec\theta$$
  • 方法二：三力平衡封閉向量三角形法（核心解法）
    物體受三個力：重力 $\vec{W}$（鉛直向下）、外力 $\vec{F}_2$（水平向右）、斜面支持力 $\vec{N}_2$（垂直斜面向上，與鉛垂線夾角亦為 $\theta$）。
    靜力平衡條件為合力為零：$\vec{W} + \vec{F}_2 + \vec{N}_2 = \vec{0}$，三力首尾相接必構成封閉直角三角形：
    由直角三角形之三角比定義： $$\cos\theta = \frac{\text{鄰邊 } W}{\text{斜邊 } N_2} \implies N_2 = \frac{W}{\cos\theta} = W\sec\theta$$ $$\tan\theta = \frac{\text{對邊 } F_2}{\text{鄰邊 } W} \implies F_2 = W\tan\theta$$
(2) 斜面施於物體的作用力為：$N_2 = \dfrac{W}{\cos\theta}$（即 $W\sec\theta$）
觀念深化

為什麼 $N_2 > N_1$？（物理直覺思考）

比較兩種情況的斜面正向力：

  • 情況 (1)：$N_1 = W\cos\theta < W$。外力平行於斜面，沒有壓迫斜面，斜面只需承受重力的垂直分量。
  • 情況 (2)：$N_2 = \frac{W}{\cos\theta} > W$。水平推力有一部分「斜向壓進斜面」（分力為 $F_2\sin\theta$），使得斜面所受的擠壓力大增！
