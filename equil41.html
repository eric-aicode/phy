靜力平衡 41：三彈簧 120 度對稱懸吊球體與形變多解

彈簧兼具伸長拉力與壓縮推力特性・鉛直合力分解・全面討論三種形變組合

1 題目情境與物理圖解

如圖所示，三根相同彈簧一端各自固定於壁面或地面，另一端相連於重量為 $W$ 的小球。當小球處於靜止平衡時，相鄰彈簧間的夾角均為 $120^\circ$（彈簧 1、2 在上方對稱分佈，彈簧 3 位於正下方）。

已知彈簧 1、2 對小球的作用力大小均為 $F$。因為題目未限定彈簧為「伸長」或「壓縮」，則彈簧 3 對小球的作用力可能為何？（多選）

📐 120° 對稱彈簧分佈與力學正交分解 彈簧 1、2 鉛直合力 = 2F cos 60° = F

2 自我檢測與即時核對 (多選題)

請考慮彈簧可能處於「伸長」或「壓縮」之所有物理情況，選出所有可能的作用力值：

A $F - W$
B $F + W$
C $W - F$
D $2F - W$
E $2F + W$

3 完整觀念解析與推導過程

$$\text{彈簧 1、2 與鉛垂線各夾 } 60^\circ \implies F_{\text{1,2 鉛直合力}} = 2F \cos 60^\circ = 2F \cdot \frac{1}{2} = F$$ $$\sum F_y = 0 \implies F_3 \text{ 量值可能為 } |F - W| \text{ 或 } F + W$$

步驟一：彈簧 1、2 之鉛直方向合力合成

相鄰三彈簧夾角皆為 $120^\circ$，由對稱性可知，上方彈簧 1 與彈簧 2 分別與鉛垂線夾 $60^\circ$ 角。

兩彈簧在水平方向分力大小相等、方向相反（$F\sin 60^\circ = F\sin 60^\circ$），自動互相抵消。

在鉛直方向上，若兩彈簧同時伸長（向上拉球）或同時壓縮（向下推球），其鉛直合力大小為：

$$F_{\text{鉛直}} = 2F \cos 60^\circ = 2F \times \frac{1}{2} = F$$

步驟二：分情況討論彈簧的形變狀態

  1. 情況一：若彈簧 1、2 皆伸長（提供向上拉力 $F$），且彈簧 3 縮短（提供向上支撐推力 $F_3$）：

    小球受向上合力 $F_3 + F$，向下受重力 $W$：

    $$F_3 + F = W \implies F_3 = W - F$$ 此情況發生在 $W > F$ 時，對應選項 (C)。
  2. 情況二：若三根彈簧皆伸長（彈簧 1、2 向上拉，彈簧 3 向下拉）：

    小球受向上拉力 $F$，向下受重力 $W$ 及彈簧 3 的向下拉力 $F_3$：

    $$W + F_3 = F \implies F_3 = F - W$$ 此情況發生在 $F > W$ 時，對應選項 (A)。
  3. 情況三：若三根彈簧皆縮短（彈簧 1、2 向下推，彈簧 3 向上推）：

    小球受向下推力 $F$ 與向下重力 $W$，彈簧 3 必須向上提供支撐力 $F_3$：

    $$F_3 = F + W$$ 對應選項 (B)。

步驟三：結論與選項整合

因為彈簧能拉亦能推，依據彈簧不同之伸長或壓縮狀態，彈簧 3 對小球的作用力可能為 $F - W$、$W - F$ 或 $F + W$。

因此，本題正確選項為 (A)(B)(C)。
