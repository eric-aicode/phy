名師解題核心技巧

⭐ 大考破題黃金心法（秒殺密技）：

1. 斜面對物體的「作用力」是指接觸合力 $\vec{R}$，即正向力 $\vec{N}$ 與摩擦力 $\vec{f}$ 的向量和：$\vec{R} = \vec{N} + \vec{f}$。
若物體處於靜止或等速運動（加速度 $\vec{a} = 0$），物體只受重力 $\vec{W}$ 與接觸力 $\vec{R}$ 兩力平衡，故 $\vec{R} + \vec{W} = 0 \implies \vec{R} = -\vec{W}$，其大小必為 $W$，方向必為鉛直向上！
2. 地面對斜面體之摩擦力 $\to$ 用「整體法」秒殺：將物體與斜面體視為一整體，水平方向並無任何外力，加速度 $a_x = 0$，故地面靜摩擦力必恆為 0！

Step 1

情境一分析：$\theta = 30^\circ$ 物體靜止

物體靜止於傾角 $30^\circ$ 的斜面上，沿斜面方向合力為 0：

$$\sum F_{\parallel} = 0 \implies f_s = W \sin 30^\circ = W \times \frac{1}{2} = \frac{1}{2}W$$

垂直斜面方向合力為 0： $$N = W \cos 30^\circ = \frac{\sqrt{3}}{2}W$$

斜面對物體的作用力即為 $\vec{R} = \vec{N} + \vec{f}_s$： $$R = \sqrt{N^2 + f_s^2} = \sqrt{\left(\frac{\sqrt{3}}{2}W\right)^2 + \left(\frac{1}{2}W\right)^2} = \sqrt{\frac{3+1}{4}}W = W \quad (\text{鉛直向上})$$

對斜面體而言，將 (木塊 + 斜面) 視為一體，水平方向系統不受外力，故地面的水平靜摩擦力： $$f_{\text{地}} = 0$$

Step 2

情境二分析：$\theta = 37^\circ$ 物體等速下滑

物體等速下滑，表示加速度 $\vec{a} = 0$，處於動態動平衡狀態：

沿斜面方向，動摩擦力恰平衡重力沿斜面的分力： $$f_k = W \sin 37^\circ = W \times \frac{3}{5} = \frac{3}{5}W$$

垂直斜面方向正向力： $$N = W \cos 37^\circ = \frac{4}{5}W$$

斜面對物體的作用力（接觸面的合力）： $$R = \sqrt{N^2 + f_k^2} = \sqrt{\left(\frac{4}{5}W\right)^2 + \left(\frac{3}{5}W\right)^2} = W \quad (\text{鉛直向上})$$

同樣利用整體法，木塊等速移動其加速度 $\vec{a}=0$，斜面體靜止 $\vec{a}=0$，整個系統質心無水平加速度，水平外力總和為 0： $$f_{\text{地}} = 0$$
