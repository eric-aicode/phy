名師解題心法・粗繩懸掛題目的三大突破思維

很多同學看到繩子成曲線（懸鏈線）就覺得必須列微積分，其實靜力平衡只需要抓準三把鑰匙：
1. 全繩「整體法」：繩重 $\vec{W}$ 與兩懸掛點張力 $\vec{T}_A, \vec{T}_B$ 構成「共面三力平衡」，三力作用線必共點！由正交分解或封閉向量三角形可秒解兩端張力。
2. 最低點 $C$ 的「幾何本質」：極值點處切線斜率為零，因此最低點 $C$ 的張力 $\vec{T}_C$ 必然純水平，沒有任何鉛直分量！
3. 截段「隔離法」：由最低點切開，隔離左半段繩 $AC$，水平方向只有 $T_A$ 的水平分量與 $T_C$ 互相抗衡，直接得出 $T_C = T_A \sin\theta_1$！

步驟 1

第 (1) 小題：以全繩為系統，求端點張力 $T_A$ 與 $T_B$

將整條均勻粗繩視為一個受力整體，受三個外力作用而維持靜止平衡：

  • 端點 $A$ 處的約束張力 $\vec{T}_A$：沿該處繩之切線向左上方拉，與鉛垂線夾角為 $\theta_1$。
  • 端點 $B$ 處的約束張力 $\vec{T}_B$：沿該處繩之切線向右上方拉，與鉛垂線夾角為 $\theta_2$。
  • 全繩總重力 $\vec{W}$：嚴格鉛直向下，作用線通過全繩質心。

【解法一：正交分解法（最穩健、最扎實的代數聯立）】

建立直角坐標系（水平向右為 $+x$，鉛直向上為 $+y$），將各力正交分解：

$$\begin{cases} \sum F_x = 0 \implies T_B \sin\theta_2 - T_A \sin\theta_1 = 0 \implies T_B = T_A \frac{\sin\theta_1}{\sin\theta_2} & \cdots \text{(式 1)} \\[2mm] \sum F_y = 0 \implies T_A \cos\theta_1 + T_B \cos\theta_2 = W & \cdots \text{(式 2)} \end{cases}$$

將 (式 1) 代入 (式 2) 消去 $T_B$：

$$T_A \cos\theta_1 + \left(T_A \frac{\sin\theta_1}{\sin\theta_2}\right) \cos\theta_2 = W$$ $$\iff T_A \left[ \frac{\sin\theta_2 \cos\theta_1 + \cos\theta_2 \sin\theta_1}{\sin\theta_2} \right] = W$$

利用高中必備三角函數和角公式：$\sin(\theta_1 + \theta_2) = \sin\theta_1 \cos\theta_2 + \cos\theta_1 \sin\theta_2$，括號中分子巧妙化簡為 $\sin(\theta_1 + \theta_2)$！

$$T_A \cdot \frac{\sin(\theta_1 + \theta_2)}{\sin\theta_2} = W \implies \mathbf{T_A = \frac{W\sin\theta_2}{\sin(\theta_1 + \theta_2)}}$$

再將 $T_A$ 代回 (式 1)，即可求出 $T_B$：

$$T_B = \left[ \frac{W\sin\theta_2}{\sin(\theta_1 + \theta_2)} \right] \cdot \frac{\sin\theta_1}{\sin\theta_2} \implies \mathbf{T_B = \frac{W\sin\theta_1}{\sin(\theta_1 + \theta_2)}}$$

【解法二：拉密定理／向量封閉三角形法（競賽幾何秒殺）】

三力不平行且達平衡，三力作用線必共點於 $O$ 點，將三向量首尾相接，必然構成一個封閉三角形（如上方思考圖 1 所示）：

  • $\vec{W}$ 與 $\vec{T}_A$ 的夾角為 $\theta_1$。
  • $\vec{W}$ 與 $\vec{T}_B$ 的夾角為 $\theta_2$。
  • 對應於 $\vec{W}$ 的第三個內角為 $180^\circ - (\theta_1 + \theta_2)$。

直接套用三角形正弦定理（即拉密定理 Lami's Theorem）：

$$\frac{W}{\sin\left[180^\circ - (\theta_1 + \theta_2)\right]} = \frac{T_A}{\sin\theta_2} = \frac{T_B}{\sin\theta_1}$$ $$\iff \frac{W}{\sin(\theta_1 + \theta_2)} = \frac{T_A}{\sin\theta_2} = \frac{T_B}{\sin\theta_1}$$

兩行即可直接得出相同的標準解，兩大方法相互印證！

步驟 2

求解最低點 $C$ 之張力 $T_C$（隔離體截段受力）

1. 最低點 $C$ 的切線幾何特徵：
點 $C$ 是全繩軌跡函數 $y(x)$ 的最低點，極值點切線斜率 $dy/dx = 0$。因此在 $C$ 點處，繩之切線方向完全水平，這意味著張力 $\vec{T}_C$ 只有水平分量，鉛直分量為零（$T_{Cy} = 0$）。

2. 隔離左半段繩 $AC$（設其重量為 $W_{AC}$）：
左半段繩 $AC$ 處於靜止平衡，其受力有：

  • 頂端 $A$ 點：繩張力 $\vec{T}_A$（向左上方，水平分量 $T_A \sin\theta_1$ 向左）。
  • 底端 $C$ 點：右段繩對左段繩之拉力 $\vec{T}_C$（純水平向右）。
  • 自身重力：$W_{AC}$（鉛直向下）。

對繩段 $AC$ 列出水平方向平衡方程式：

$$\sum F_x = 0 \implies T_C = T_A \sin\theta_1$$

將步驟 1 所求之 $T_A$ 代入：

$$T_C = \left[ \frac{W\sin\theta_2}{\sin(\theta_1 + \theta_2)} \right] \cdot \sin\theta_1 \implies \mathbf{T_C = W \frac{\sin\theta_1 \sin\theta_2}{\sin(\theta_1 + \theta_2)}}$$

3. 驗算——隔離右半段繩 $CB$：
同理，右半段繩 $CB$ 水平方向受向左的 $T_C$ 與向右的 $T_B \sin\theta_2$： $$T_C = T_B \sin\theta_2 = \left[ \frac{W\sin\theta_1}{\sin(\theta_1 + \theta_2)} \right] \cdot \sin\theta_2 = W \frac{\sin\theta_1 \sin\theta_2}{\sin(\theta_1 + \theta_2)}$$ 兩側推導完全吻合，確證 $T_C$ 運算無懈可擊！

💡 延伸收穫（左右兩段繩重分配）：
由鉛直平衡可知：左段重 $W_{AC} = T_A \cos\theta_1 = W \frac{\sin\theta_2 \cos\theta_1}{\sin(\theta_1+\theta_2)}$，右段重 $W_{CB} = T_B \cos\theta_2 = W \frac{\sin\theta_1 \cos\theta_2}{\sin(\theta_1+\theta_2)}$。
兩段重量相加剛好為 $W$，清晰揭示了最低點兩側繩長的質量配置比為 $W_{AC} : W_{CB} = \tan\theta_2 : \tan\theta_1$！

步驟 3

第 (2) 小題完整證明：繩上任一點張力之水平分量均相同

題目要求說明「繩上任一點張力之水平分量值均相同」，可由下列兩種視角嚴密說明：

【視角一：微元分析法（微分形式嚴謹證明）】

在均勻粗繩上任意位置截取長度為 $\Delta s$ 的微小繩段。該微段處於平衡狀態，所受外力為：

  • 兩端切線方向之拉伸張力：$\vec{T}(s)$ 與 $\vec{T}(s + \Delta s)$。
  • 該微段自身之微小重力：$\Delta m \cdot \vec{g}$。

因為重力方向完全沿鉛直向下，在水平方向之分量嚴格為零（$g_x = 0$）。因此在水平方向上，唯一的受力來源就是兩端張力的水平分量：

$$\sum F_x = 0 \implies T_x(s + \Delta s) - T_x(s) = 0 \implies \frac{dT_x}{ds} = 0$$

張力水平分量對繩長坐標之導數為零，這在數學與物理上直接證明了：整條粗繩上無論何處，張力之水平分量 $T_x$ 均為定值（常數）！

【視角二：任意截段平衡法（宏觀代數直觀說明）】

在粗繩上任意指定一點 $P$（切線與鉛垂線夾角為 $\theta$），將繩索從 $P$ 點切開，隔離從端點 $A$ 到 $P$ 點的繩段 $AP$：

  • 左端 $A$ 處受張力 $\vec{T}_A$，向左的水平分量為 $T_A \sin\theta_1$。
  • 右端 $P$ 處受張力 $\vec{T}_P$，向右的水平分量為 $T_P \sin\theta$。
  • 繩段 $AP$ 自身的重力 $\vec{W}_{AP}$ 純粹垂直向下，無水平分量。

由該繩段的水平靜力平衡：

$$\sum F_x = 0 \implies T_P \sin\theta = T_A \sin\theta_1 = \text{常數} = T_C$$

由於點 $P$ 是繩上隨意選取的任意點，這明確證明了：繩上任何一點的張力水平分量皆完全相等，且恆等於最低點 $C$ 的張力量值 $T_C$！

✅ 本題標準答案與結論彙整：
(1) 各點張力大小：
• 端點 A 張力：$$T_A = \frac{W\sin\theta_2}{\sin(\theta_1 + \theta_2)}$$
• 端點 B 張力：$$T_B = \frac{W\sin\theta_1}{\sin(\theta_1 + \theta_2)}$$
• 最低點 C 張力：$$T_C = W \frac{\sin\theta_1 \sin\theta_2}{\sin(\theta_1 + \theta_2)}$$
(2) 水平分量恆定性： 因全繩僅受鉛直向下之重力，水平方向無任何外力分量，故任意繩段之水平合力必為零，證明繩上任一點張力水平分量皆恆等於 $T_C = T_A\sin\theta_1 = T_B\sin\theta_2$。
故選擇題正確選項為 (A)。

⚡ 觀念延伸・懸鏈線（Catenary）四大黃金物理性質：

  1. 張力分佈規律：任一點張力 $T = \sqrt{T_x^2 + T_y^2}$。因為水平分量 $T_x$ 處處相等，而鉛直分量 $T_y$ 等於該截點以下繩段的總重量。因此越往高處張力越大，在最低點 $C$ 達到全繩最小值 $T_{\min} = T_C$！
  2. 兩牆等高懸掛特例（對稱性 $\theta_1 = \theta_2 = \theta$）：
    • $T_A = T_B = \frac{W\sin\theta}{\sin(2\theta)} = \frac{W\sin\theta}{2\sin\theta\cos\theta} = \frac{W}{2\cos\theta}$
    • 最低點張力：$T_C = \frac{W\sin^2\theta}{2\sin\theta\cos\theta} = \frac{W}{2}\tan\theta$
  3. 「拉不直的繩子」之謎：
    若想將均勻粗繩拉成完全水平，即 $\theta \to 90^\circ$，此時 $\cos\theta \to 0$，所需張力 $T \to \infty$。這說明在地球重力場中，任何有質量的繩索都絕對不可能被拉成絕對水平直線！
  4. 若為無質量輕繩：若不計繩重（$W = 0$），繩子只在兩端受力，將退化為直線，此時整條繩子張力處處相等。
