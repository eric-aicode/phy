聯考經典圓柱堆疊力學題

如圖所示，$A$、$B$、$C$ 三個光滑圓柱，半徑均為 $50\text{ cm}$。今將 $A$、$B$ 置於光滑水平地面並以一鋼繩連接，鋼繩長 $160\text{ cm}$。已知 $C$ 柱重 $200\text{ kgw}$，$A$、$B$ 各重 $100\text{ kgw}$，鋼繩重量不計。當系統呈靜力平衡時，試求：
(1) $A$、$C$ 兩圓柱間之相互作用力為多少 $\text{kgw}$？
(2) 作用在連接 $A$、$B$ 之鋼繩上的張力為多少 $\text{kgw}$？

🏛️ 解法一【正交分解與隔離法】核心解析：
• 頂柱 C 鉛直平衡：受自身重力 $W_C = 200\text{ kgw}$ 向下，兩底柱向上支持力左右對稱。鉛直分量平衡列式： $$2 F_{AC} \cos 53^\circ = 200 \implies 2 F_{AC} \left(\frac{3}{5}\right) = 200 \implies \mathbf{F_{AC} = \frac{500}{3}\text{ kgw}}$$
• 底柱 B 水平平衡：受頂柱斜向推力 $F_{BC}$，其向外推開的水平分量由鋼繩張力 $T$ 完全拉住： $$T = F_{BC} \sin 53^\circ = \left(\frac{500}{3}\right) \times \left(\frac{4}{5}\right) = \mathbf{\frac{400}{3}\text{ kgw}}$$
📐 解法二【幾何相似三角形（3:4:5 比例法）】秒殺密技：
• 力三角形與空間幾何三角形嚴格相似：頂柱半邊受力構成直角封閉三角形，三邊方向恰好與連心線構成的空間三角形（鉛直高 $60\text{ cm}$ 對應比例 3、底邊 $80\text{ cm}$ 對應比例 4、斜邊 $100\text{ cm}$ 對應比例 5）完全平行相似！
• 免算三角函數，直接比例秒出答案： $$\frac{F_{AC}}{5} = \frac{T}{4} = \frac{\frac{1}{2}W_C}{3} = \frac{100}{3}$$ $$\mathbf{F_{AC} = 100 \times \frac{5}{3} = \frac{500}{3}\text{ kgw}} \quad , \quad \mathbf{T = 100 \times \frac{4}{3} = \frac{400}{3}\text{ kgw}}$$

幾何分析

連心線三角形尺寸與角度

各圓柱半徑均為 $r = 50\text{ cm}$：

  • 圓柱 $A$、$C$ 相切，連心線長度：$AC = 50 + 50 = 100\text{ cm}$。
  • 圓柱 $B$、$C$ 相切，連心線長度：$BC = 50 + 50 = 100\text{ cm}$。
  • 圓柱 $A$、$B$ 間距由鋼繩限制為 $AB = 160\text{ cm}$。

由對稱性，通過 $C$ 的鉛垂線將底邊等分為兩半，每邊長 $80\text{ cm}$。
在半邊直角三角形中： $$\text{高 } h = \sqrt{100^2 - 80^2} = \sqrt{10000 - 6400} = \sqrt{3600} = 60\text{ cm}$$ 此直角三角形之三邊比為 $60 : 80 : 100 = 3 : 4 : 5$！
連心線 $AC$ 與鉛垂線之夾角為 $53^\circ$（$\cos 53^\circ = \frac{3}{5} = 0.6$，$\sin 53^\circ = \frac{4}{5} = 0.8$）。

步驟 1

隔離 C 圓柱求相互作用力 $F_{AC}$（第 1 小題）

$C$ 圓柱重 $W_C = 200\text{ kgw}$，受 $A$ 與 $B$ 斜向上的正向支持力 $F_{AC}$ 與 $F_{BC}$。
由對稱性 $F_{AC} = F_{BC}$，鉛直方向合力為零： $$2 F_{AC} \cos 53^\circ = W_C \implies 2 F_{AC} \left(\frac{3}{5}\right) = 200$$ $$\frac{6}{5} F_{AC} = 200 \implies F_{AC} = 200 \times \frac{5}{6} = \frac{500}{3}\text{ kgw}$$

步驟 2

隔離 B 圓柱求鋼繩張力 $T$（第 2 小題）

$B$ 圓柱受到四個力作用：

  • $C$ 對 $B$ 的正向推力 $F_{BC} = \frac{500}{3}\text{ kgw}$（斜向右下，與鉛垂線夾 $53^\circ$）。
  • 重力 $W_B = 100\text{ kgw}$（鉛直向下）。
  • 地面正向支持力 $N_B$（鉛直向上）。
  • 鋼繩張力 $T$（水平向左拉住 $B$）。

列水平方向合力為零： $$T = F_{BC} \sin 53^\circ = \left(\frac{500}{3}\right) \times \frac{4}{5} = \frac{400}{3}\text{ kgw}$$

另解技巧

解法二：幾何相似三角形法（3:4:5 比例法秒殺）

① 力的三角形與空間連心線三角形完全平行相似：
考慮頂柱 $C$ 的受力平衡：受到鉛直重力 $W_C = 200\text{ kgw}$ 向下，兩側支持力 $F_{AC}$ 與 $F_{BC}$ 向上。
由對稱性取頂柱的半邊系統：
• 鉛直向下分量為半重力 $\frac{1}{2}W_C = 100\text{ kgw}$，恰對應空間幾何三角形的鉛直高 $h = 60\text{ cm}$（比例數值為 $3$）。
• 水平向外推力分量 $F_x$ 恰由鋼繩張力 $T$ 平衡，對應幾何三角形的水平半底邊 $80\text{ cm}$（比例數值為 $4$）。
• 斜向支持力 $F_{AC}$ 沿連心線方向，對應幾何三角形的斜邊 $100\text{ cm}$（比例數值為 $5$）。

② 列相似比一步到位（完全免算三角函數）：
$$\frac{F_{AC}}{5} = \frac{T}{4} = \frac{\frac{1}{2}W_C}{3} = \frac{100}{3}$$ 直接求出兩小題答案： $$F_{AC} = 100 \times \frac{5}{3} = \frac{500}{3}\text{ kgw}$$ $$T = 100 \times \frac{4}{3} = \frac{400}{3}\text{ kgw}$$

結論： 本題正確答案為 (A) (1) $\frac{500}{3}\text{ kgw}$；(2) $\frac{400}{3}\text{ kgw}$。
