平面共點力合成基礎考題

在一光滑水平的桌面上面有一很輕的小銅環，被三條細線拉住，細線對銅環的作用力方向，如下圖所示。
已知三力之量值分別為：

  • $F_1 = \mathbf{25\text{ kgw}}$（沿 $+x$ 軸方向）
  • $F_2 = \mathbf{15\text{ kgw}}$（與 $\vec{F}_1$ 夾角為 $127^\circ$）
  • $F_3 = \mathbf{30\text{ kgw}}$（與 $\vec{F}_2$ 垂直且指向第三象限，夾角為 $90^\circ$）
試求：此銅環所受的合力大小為何？其方向與 $+x$ 方向的夾角 $\theta$ 為何？

💡 名師思考引導：

  1. 常用三角比：$\sin 37^\circ = \cos 53^\circ = 0.6$，$\cos 37^\circ = \sin 53^\circ = 0.8$。
  2. $F_2$ 分解：與 $+x$ 軸夾 $127^\circ$ $\implies$ 與 $-x$ 軸夾 $180^\circ - 127^\circ = 53^\circ$。位在第二象限，$x$ 為負、$y$ 為正：$F_{2x} = -15 \cos 53^\circ = -9$，$F_{2y} = +15 \sin 53^\circ = +12$。
  3. $F_3$ 分解：與 $F_2$ 垂直（$90^\circ$）且在第三象限 $\implies$ 方向角為 $127^\circ + 90^\circ = 217^\circ$，與 $-x$ 軸夾 $37^\circ$。位在第三象限，$x$ 為負、$y$ 為負：$F_{3x} = -30 \cos 37^\circ = -24$，$F_{3y} = -30 \sin 37^\circ = -18$。
  4. 合力合成：$R_x = 25 + (-9) + (-24) = -8$，$R_y = 0 + 12 + (-18) = -6$。由商高定理 $R = \sqrt{(-8)^2 + (-6)^2} = 10\text{ kgw}$！

完整圖解解析

正交分解法與向量多邊形合成詳解
步驟 1

建立直角坐標系並標註各力角度

取銅環為原點 $(0, 0)$，水平向右為 $+x$ 軸，鉛直向上為 $+y$ 軸。

• $\vec{F}_1$：大小 $25\text{ kgw}$，方向沿 $+x$ 軸（方向角 $0^\circ$）。
• $\vec{F}_2$：大小 $15\text{ kgw}$，方向角 $127^\circ$（位在第二象限，與 $-x$ 夾角為 $180^\circ - 127^\circ = 53^\circ$）。
• $\vec{F}_3$：大小 $30\text{ kgw}$，與 $\vec{F}_2$ 垂直（$90^\circ$），方向角為 $127^\circ + 90^\circ = 217^\circ$（位在第三象限，與 $-x$ 夾角為 $37^\circ$）。

步驟 2

各力之正交分量（$x$ 與 $y$ 方向）

利用 $\cos 53^\circ = \sin 37^\circ = 0.6$，$\sin 53^\circ = \cos 37^\circ = 0.8$ 計算各向量分量：

$$\vec{F}_1 = (25, \; 0)\text{ kgw}$$ $$\vec{F}_2 = (-15\cos 53^\circ, \; 15\sin 53^\circ) = (-15 \times 0.6, \; 15 \times 0.8) = (-9, \; 12)\text{ kgw}$$ $$\vec{F}_3 = (-30\cos 37^\circ, \; -30\sin 37^\circ) = (-30 \times 0.8, \; -30 \times 0.6) = (-24, \; -18)\text{ kgw}$$
步驟 3

求合力分量 $\vec{R} = \vec{F}_1 + \vec{F}_2 + \vec{F}_3$

將三向量之分量分別相加：

$$R_x = F_{1x} + F_{2x} + F_{3x} = 25 + (-9) + (-24) = -8\text{ kgw}$$ $$R_y = F_{1y} + F_{2y} + F_{3y} = 0 + 12 + (-18) = -6\text{ kgw}$$

故合力向量為 $\vec{R} = (-8, \; -6)\text{ kgw}$。

步驟 4

計算合力量值與方向角 $\theta$

由商高定理求得合力大小：

$$R = \sqrt{R_x^2 + R_y^2} = \sqrt{(-8)^2 + (-6)^2} = \sqrt{64 + 36} = \mathbf{10\text{ kgw}}$$

方向判斷：因 $R_x = -8 < 0$ 且 $R_y = -6 < 0$，合力位於第三象限。 與 $-x$ 軸（負水平方向）之夾角為： $$\tan \phi = \left|\frac{R_y}{R_x}\right| = \frac{6}{8} = \frac{3}{4} \implies \phi = 37^\circ$$ 因此與 $+x$ 方向的逆時針方向夾角為： $$\theta = 180^\circ + 37^\circ = \mathbf{217^\circ}$$

✅ 最終標準解答：
合力大小為 $10\text{ kgw}$，方向與 $+x$ 方向夾角為 $\theta = 217^\circ$（或寫為 $(-8, -6)\text{ kgw}$）。
👨‍🏫

名師點撥・幾何圖解的巧妙秒殺法

注意到 $\vec{F}_2$ 與 $\vec{F}_3$ 互相垂直（$90^\circ$）！
先合成 $\vec{F}_{23} = \vec{F}_2 + \vec{F}_3$：
$|\vec{F}_{23}| = \sqrt{15^2 + 30^2} = 15\sqrt{5}$。
但使用直角坐標正交分解（即講義原筆記作法）更不容易出錯，因為 $37^\circ$ 與 $53^\circ$ 的三角比直接給出整數分量 $(-9, 12)$ 與 $(-24, -18)$，加減極為迅速精準！
