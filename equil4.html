幾何破解

由三邊長度求結點頂角 $\angle ACB$

在 $\triangle ABC$ 中，已知三邊長分別為 $AC = l$、$BC = l$、$AB = \sqrt{3}l$：

  • 法一（餘弦定理）： $$\cos(\angle ACB) = \frac{AC^2 + BC^2 - AB^2}{2 \cdot AC \cdot BC} = \frac{l^2 + l^2 - (\sqrt{3}l)^2}{2 \cdot l \cdot l} = \frac{2l^2 - 3l^2}{2l^2} = -\frac{1}{2}$$ $$\implies \angle ACB = 120^\circ$$
  • 法二（特殊直角三角形）： 作頂角平分線垂直平分底邊 $AB$，兩半邊底長均為 $\frac{\sqrt{3}}{2}l$。
    斜邊為 $l$，對邊為 $\frac{\sqrt{3}}{2}l$，故半角 $\sin\alpha = \frac{\sqrt{3}}{2} \implies \alpha = 60^\circ$。
    全頂角 $\angle ACB = 2\alpha = 120^\circ$。
力學平衡

結點 C 之三力平衡分析（三種秒殺途徑）

結點 C 受到三個力的作用：AC 繩張力 $T_{AC}$、BC 繩張力 $T_{BC}$、CD 繩張力 $T_{CD} = mg$（鉛直向下）。

  • 途徑一：拉密定理 (Lami's Theorem)
    鉛垂繩 CD 恰好平分對稱角，故三個力兩兩之間的夾角分別為： $$\angle(T_{AC}, T_{BC}) = 120^\circ, \quad \angle(T_{AC}, mg) = 120^\circ, \quad \angle(T_{BC}, mg) = 120^\circ$$ 由拉密定理： $$\frac{T_{AC}}{\sin 120^\circ} = \frac{T_{BC}}{\sin 120^\circ} = \frac{mg}{\sin 120^\circ} \implies T_{AC} = T_{BC} = mg$$
  • 途徑二：封閉向量三角形
    三個力向量首尾相接形成封閉三角形。因為兩兩外角為 $120^\circ$，其三角形內角皆為 $180^\circ - 120^\circ = 60^\circ$！
    這是一個正三角形（等邊三角形）！
    因此三邊長度皆相等，直接得出： $$T_{AC} = T_{BC} = mg$$
  • 途徑三：鉛直方向正交分解
    繩與鉛直線夾角為 $60^\circ$： $$2 T_{AC} \cos 60^\circ = mg \implies 2 T_{AC} \left(\frac{1}{2}\right) = mg \implies T_{AC} = mg$$
繩 AC 張力 $T_{AC} = mg$

故正確答案為 (C)。
