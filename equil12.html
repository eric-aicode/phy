靜力平衡 12：兩球夾壓縮彈簧平衡形變量

結構對稱性・單球隔離體分析・正切關係與虎克定律

題目內容

聯考與競賽對稱平衡經典題

重量均為 $W$ 的 $A$、$B$ 兩小球，用兩根長度均為 $L$ 的輕繩懸掛於同一頂點，兩球之間夾一力常數為 $k$ 的輕彈簧。平衡時兩懸繩之夾角為 $60^\circ$（如圖所示），則此時彈簧被壓縮的長度是多少？

請依上述物理條件，推導彈簧的壓縮量 $x$ 為何？

A
$\dfrac{W}{k}$
B
$\dfrac{\sqrt{3}W}{k}$
C
$\dfrac{W}{\sqrt{3}k}$
D
$\dfrac{W}{2k}$
E
$\dfrac{\sqrt{3}W}{2k}$

核心解析與詳細推導

點擊展開 / 收合完整解析
點擊展開完整剖析
步驟 1

由系統對稱性求懸繩傾角

頂點 $O$ 懸掛兩條長度同為 $L$ 的輕繩，分別繫著重量同為 $W$ 的兩球 $A$ 與 $B$。
系統對通過 $O$ 點的鉛垂線具有完全對稱性。當兩懸繩間總夾角為 $60^\circ$ 時，每根懸繩與鉛直方向的夾角 $\theta$ 為： $$\theta = \frac{60^\circ}{2} = 30^\circ$$

步驟 2

隔離單一小球（以 A 球為例）受力分析

彈簧被壓縮，兩端產生向外的推力 $F$。對 $A$ 球而言，彈力 $F$ 向左；對 $B$ 球而言，彈力 $F$ 向右。
以 $A$ 球為受力主體，其共受三個力作用並達靜力平衡：

  • 重力 $W$：方向鉛直向下。
  • 彈簧彈力 $F$：方向水平向左，大小 $F = kx$（$x$ 為壓縮量）。
  • 輕繩張力 $T$：沿懸繩斜向上，與鉛垂線夾角為 $30^\circ$。
直角三角形

三力構成封閉直角三角形秒出彈力

重力 $W$ 鉛直向下，彈力 $F$ 水平向左，兩力相互垂直。繩張力 $T$ 作為斜邊，三力首尾相接恰構成直角三角形：

$$\tan 30^\circ = \frac{\text{水平彈力 } F}{\text{鉛直重力 } W} \implies F = W \tan 30^\circ = \frac{W}{\sqrt{3}} = \frac{\sqrt{3}}{3}W$$

繩張力亦可直接由餘弦求得： $$T = \frac{W}{\cos 30^\circ} = \frac{W}{\frac{\sqrt{3}}{2}} = \frac{2\sqrt{3}}{3}W$$

正交分解

水平與鉛直獨立平衡聯立求解

將繩張力 $T$ 分解至水平與鉛直軸：

  • 鉛直方向平衡： $$\Sigma F_y = 0 \implies T \cos 30^\circ = W \implies T = \frac{W}{\cos 30^\circ} = \frac{2}{\sqrt{3}}W$$
  • 水平方向平衡： $$\Sigma F_x = 0 \implies F = T \sin 30^\circ = \left(\frac{2}{\sqrt{3}}W\right)\cdot \frac{1}{2} = \frac{W}{\sqrt{3}}$$
步驟 4

代入虎克定律求壓縮量 $x$

根據虎克定律 $F = k \cdot x$： $$kx = \frac{W}{\sqrt{3}} \implies x = \frac{W}{\sqrt{3}k} = \frac{\sqrt{3}W}{3k}$$

結論： 本題正確答案為 (C) $\dfrac{W}{\sqrt{3}k}$。
