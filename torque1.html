核心定義

力矩（Torque）與力臂的物理意義

力矩之大小等於「作用力大小 $F$ 乘以支點到力之作用線的垂直距離 $d$（即力臂）」： $$\tau = F \times d$$

  • 若作用力的作用線通過支點，則其垂直距離（力臂）$d = 0$，此力對該支點所產生的力矩必為零（$\tau = 0$）。
幾何推導

任選一頂點作為參考支點（以頂點 A 為例）

正三角形板邊長為 $a$，內角皆為 $60^\circ$。若選取頂點 A 為支點：

  1. 沿邊 $AB$ 作用的力 $F$：其延長線恰好通過頂點 A，力臂 $d = 0 \implies \tau_1 = 0$。
  2. 沿邊 $CA$ 作用的力 $F$：其延長線亦恰好通過頂點 A，力臂 $d = 0 \implies \tau_2 = 0$。
  3. 沿對邊 $BC$ 作用的力 $F$：其作用線不通過頂點 A。 頂點 A 到對邊 $BC$ 的垂直距離即為正三角形的高 $h$： $$d = h = a \sin 60^\circ = \frac{\sqrt{3}}{2}a$$ 因此其產生的力矩為： $$\tau_3 = F \times d = F \times \left(\frac{\sqrt{3}}{2}a\right) = \mathbf{\frac{\sqrt{3}}{2}Fa}$$
對稱性總結

對頂點 B 或 C 亦完全等價

若改選頂點 B 為支點，則沿 $AB$ 與 $BC$ 之兩力通過 B 點（力矩為 0），僅剩沿 $AC$ 之力提供力矩；
若改選頂點 C 為支點，則沿 $BC$ 與 $CA$ 之兩力通過 C 點（力矩為 0），僅剩沿 $AB$ 之力提供力矩。
因此，對正三角形之任一頂點，合力矩量值恆為 $\mathbf{\frac{\sqrt{3}}{2}Fa}$！

結論

本題正解為 (C) $\frac{\sqrt{3}}{2}Fa$。
解力矩題目的第一黃金法則：善用通過支點的力力矩為零，可以瞬間將多力問題化簡為單力計算！
