講義經典指標題

一物重 $10\text{ kgw}$，以兩細繩及一輕彈簧吊起平衡如下圖所示。
已知：

  • 兩細繩與水平天花板之夾角分別為 $30^\circ$ 與 $60^\circ$
  • 兩細繩中較長者長度為 $4.0\text{ cm}$
  • 彈簧鉛直懸掛，原長為 $1.5\text{ cm}$，力常數 $k = \mathbf{800\text{ kgw/m}}$
試求：較長之細繩上張力為多少 $\text{kgw}$？

💡 名師思考引導：

  1. 幾何直角性：天花板水平，兩繩仰角分別為 $30^\circ$ 與 $60^\circ$ $\implies$ 兩繩夾角為 $180^\circ - (30^\circ + 60^\circ) = 90^\circ$（互相垂直！）。
  2. 求節點深度 $h$：長繩長度 $4.0\text{ cm}$，仰角 $30^\circ$ $\implies$ 鉛直深度 $h = 4.0 \times \sin 30^\circ = 2.0\text{ cm}$。
  3. 彈簧彈力：伸長量 $\Delta x = h - L_0 = 2.0 - 1.5 = 0.5\text{ cm} = 0.005\text{ m}$。彈力 $F_s = k \times \Delta x = 800 \times 0.005 = 4\text{ kgw}$。
  4. 向量三角形：向上有彈簧 $4\text{ kgw}$，向下有重力 $10\text{ kgw}$，等效為鉛直向下外力 $W - F_s = 6\text{ kgw}$。兩繩張力與 $6\text{ kgw}$ 形成以 $6\text{ kgw}$ 為斜邊的直角三角形！
💡

完整圖解解析

幾何與向量封閉三角形精解
步驟 1

幾何求解：節點至天花板之鉛直距離 $h$

長繩長度 $L_1 = 4.0\text{ cm}$，與天花板夾角為 $30^\circ$。節點的鉛直深度即為長繩的對邊高：

$$h = L_1 \times \sin 30^\circ = 4.0\text{ cm} \times \frac{1}{2} = \mathbf{2.0\text{ cm}}$$
步驟 2

虎克定律：求彈簧伸長量與彈力 $F_s$

彈簧原長 $L_0 = 1.5\text{ cm}$，現長度拉伸至節點位置 $h = 2.0\text{ cm}$：

$$\Delta x = h - L_0 = 2.0\text{ cm} - 1.5\text{ cm} = 0.5\text{ cm} = 0.005\text{ m}$$ $$F_s = k \times \Delta x = 800\text{ kgw/m} \times 0.005\text{ m} = \mathbf{4.0\text{ kgw}}$$
步驟 3

鉛直淨外力合成

節點處受到向下的物重 $W = 10\text{ kgw}$ 以及彈簧向上的拉力 $F_s = 4.0\text{ kgw}$。兩力共線合成：

$$F_{\text{net}} = W - F_s = 10\text{ kgw} - 4\text{ kgw} = \mathbf{6.0\text{ kgw}} \quad (\text{向下})$$
步驟 4

向量封閉直角三角形求解張力 $T_1$

兩細繩相互垂直（$30^\circ + 60^\circ = 90^\circ$），因此張力 $\vec{T}_1$、$\vec{T}_2$ 與鉛直外力 $\vec{F}_{\text{net}}$ 首尾相接構成直角三角形，其中斜邊長為 $6.0\text{ kgw}$。

長繩張力 $\vec{T}_1$ 與鉛垂線的夾角為 $90^\circ - 30^\circ = 60^\circ$：

$$T_1 = F_{\text{net}} \times \cos 60^\circ = 6.0 \times \frac{1}{2} = \mathbf{3.0\text{ kgw}}$$ $$T_2 = F_{\text{net}} \times \sin 60^\circ = 6.0 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}\text{ kgw}$$
✅ 最終標準解答： 較長之細繩上張力為 $3\text{ kgw}$。
👨‍🏫

名師解題心法・向量三角形速度之王

只要看到兩條繩子夾角互餘（$30^\circ$-$60^\circ$ 或 $37^\circ$-$53^\circ$），繩子彼此必互相垂直！
此時不需要列水平與鉛直兩個聯立方程式，直接畫出以淨向下外力為斜邊的封閉直角三角形，張力一秒即刻算出！
