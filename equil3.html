核心觀念

名詞解析：「地面對物體的作用力」不是只有正向力！

物理學中，接觸面施予物體的作用力稱為接觸力（全作用力 $\vec{R}$）：

  • 垂直接觸面的分量： 正向支持力 $\vec{N}$。
  • 平行接觸面的分量： 摩擦力 $\vec{f}$（本題為靜摩擦力）。
  • 接觸面全作用力： 為兩垂直分量的向量和，量值滿足勾股定理： $$R = \sqrt{N^2 + f^2}$$
⚠️ 大考陷阱提醒： 如果題目問「地面支持力」或「正向力」，答案才是 $N = W + F\sin 30^\circ$；但題目問「地面對物體之作用力」，必須將摩擦力一同計入向量合成！
步驟推導

正交分解列平衡方程式

外力 $F$ 與水平夾角為 $30^\circ$ 斜向下推：

  • 水平方向： 木塊維持靜止，水平合力為零： $$f = F \cos 30^\circ = \frac{\sqrt{3}}{2}F$$
  • 鉛直方向： 木塊鉛直不運動，鉛直合力為零： $$N = W + F \sin 30^\circ = W + \frac{1}{2}F$$

地面作用力量值為：

$$R = \sqrt{N^2 + f^2} = \sqrt{\left(W + \frac{1}{2}F\right)^2 + \left(\frac{\sqrt{3}}{2}F\right)^2}$$

展開代數式化簡：

$$R = \sqrt{\left(W^2 + WF + \frac{1}{4}F^2\right) + \frac{3}{4}F^2} = \sqrt{W^2 + WF + F^2}$$
地面作用力 $R = \sqrt{\left(W + \frac{1}{2}F\right)^2 + \left(\frac{\sqrt{3}}{2}F\right)^2} = \sqrt{W^2 + WF + F^2}$
妙招秒殺

三力平衡向量封閉三角形法

木塊共受三個力：外力 $\vec{F}$、重力 $\vec{W}$、地面總作用力 $\vec{R}$。
由於三力平衡，合力為零，三力必首尾相接構成封閉三角形：

$$\vec{R} + \vec{F} + \vec{W} = 0 \implies \vec{R} = -(\vec{F} + \vec{W})$$

這表示 $\vec{R}$ 的量值恰好等於外力 $\vec{F}$ 與重力 $\vec{W}$ 的向量合力量值！
外力 $\vec{F}$（斜向下，與水平夾 $30^\circ$，即與向下夾 $60^\circ$）與重力 $\vec{W}$（鉛直向下）之間的夾角為： $$\phi = 90^\circ - 30^\circ = 60^\circ$$

由向量合成餘弦定理直接秒殺：

$$R = \sqrt{W^2 + F^2 + 2WF\cos 60^\circ} = \sqrt{W^2 + F^2 + 2WF\left(\frac{1}{2}\right)} = \sqrt{W^2 + WF + F^2}$$

故正確答案為 (D)。
