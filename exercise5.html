練習 5：雙彈簧串聯吊重與平臺交互作用力

隔離體分析法・系統整體法・兩彈簧伸長量疊加求總長度 $\overline{AB}$

題目內容

聯考經典串聯彈簧綜合題

原長均為 $20\text{ cm}$，彈力常數 $k = 2.0\text{ gw/cm}$ 之完全相同的輕彈簧兩條 a、b（質量不計）。

質量均為 $10\text{ g}$（即重 $10\text{ gw}$）之重物 m、n 兩個如附圖連接，彈簧 a 之上端固定在 A，重物 n 放在水平平臺 B 上，則全體保持鉛直靜態平衡。

當平臺 B 與重物 n 之間的交互作用力（支持正向力）為 $5.0\text{ gw}$ 時，A、B 兩點之間的距離 $\overline{AB}$ 為多少 $\text{cm}$？

完整精闢觀念解析與公式推導

名師詳解
Step 1

隔離重物 n，求彈簧 b 之拉力 $F_b$

隔離最下方的物體 n，物體 n 處於靜力平衡：

  • 向下重力：$W_n = 10\text{ gw}$
  • 平臺 B 向上的支持正向力：$N = 5.0\text{ gw}$
  • 彈簧 b 向上的拉力：$F_b$

由鉛直力平衡： $$\sum F_y = 0 \implies F_b + N = W_n$$ $$F_b + 5.0 = 10 \implies F_b = 5.0\text{ gw}$$

Step 2

系統整體法（或隔離 m），求彈簧 a 之拉力 $F_a$

將 $(m + n)$ 視為一整體系統，內力（彈簧 b 之張力）相互抵消，系統鉛直受力：

  • 向下總重力：$W_m + W_n = 10 + 10 = 20\text{ gw}$
  • 平臺 B 向上的支持力：$N = 5.0\text{ gw}$
  • 彈簧 a 向上的懸吊拉力：$F_a$

由整體鉛直平衡： $$F_a + N = W_{\text{總}} \implies F_a + 5.0 = 20$$ $$F_a = 15.0\text{ gw}$$

Step 3

計算彈簧伸長量並求總長度 $\overline{AB}$

由虎克定律 $\Delta x = \frac{F}{k}$，已知力常數 $k = 2.0\text{ gw/cm}$：

$$\Delta x_a = \frac{F_a}{k} = \frac{15.0\text{ gw}}{2.0\text{ gw/cm}} = 7.5\text{ cm}$$ $$\Delta x_b = \frac{F_b}{k} = \frac{5.0\text{ gw}}{2.0\text{ gw/cm}} = 2.5\text{ cm}$$

兩重物質量雖計，但質點體積可忽略不計，A、B 兩點間之總距離即為兩彈簧長度之和：

$$\overline{AB} = L_a + L_b = (L_0 + \Delta x_a) + (L_0 + \Delta x_b)$$ $$\overline{AB} = (20 + 7.5) + (20 + 2.5) = 27.5 + 22.5 = 50\text{ cm}$$

答案：$\overline{AB} = 50\text{ cm}$
