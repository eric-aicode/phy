範例 7：高架工作車之翻覆臨界力矩

支點選擇技巧・前輪正向力為零之臨界狀態・多質點力臂幾何運算

題目內容

99年度指定科目考試試題

下圖為在水平面上的高架工作車示意圖。車體質量為 $M$（不含支架），質心恰在前輪軸正上方，前後輪軸間距為 $a$。

均質支架質量為 $M/8$，支架底端的支點恰在後輪軸正上方。支架頂端工作台與人員總質量為 $M/4$，質心恰在支架頂端正上方。

設工作時支架與鉛垂線的夾角為 $30^\circ$，要使車體不至翻覆，支架長度最大可為多少？

選項： (A) $8a$    (B) $32a/5$    (C) $16a/3$    (D) $16a/5$    (E) $a/8$

💡 名師思考引導：

  1. 轉軸選擇：當支架向右後方傾斜伸長時，車體若要翻覆必以後輪接觸點為轉軸向後翻！
  2. 翻覆臨界條件：恰不翻覆的臨界狀態，前輪正向力恰好降為零（$N_{\text{前}} = 0$）。
  3. 車體質心位置：題目清楚說明「質心恰在前輪軸正上方」，所以車體重力 $Mg$ 對後輪軸的力臂整整就是輪距 $a$，提供向左下壓的順時針穩定力矩 $\tau_{\text{順}} = Mg \cdot a$！
  4. 支架與人員力矩：支架質心在中點（距後輪軸 $L/2$），力臂為 $\frac{L}{2}\sin 30^\circ = \frac{L}{4}$；頂端工作台在頂點（距後輪軸 $L$），力臂為 $L\sin 30^\circ = \frac{L}{2}$。兩者皆提供向後拉倒的逆時針力矩。令順時針力矩＝逆時針力矩即可秒殺！
💡

完整圖解解析

轉軸力矩平衡與翻覆臨界標準推導
步驟 1

確定轉動支點與臨界翻覆狀態

工作車支架向後上方伸長，若長度過長將向後翻倒，因此翻覆轉動之轉軸必在後輪接觸點 P。

當支架長度達到最大臨界值 $L_{\max}$ 時，車體恰好即將離地，此時前輪正向力 $N_{\text{前}} = 0$。

步驟 2

分析各重力對後輪軸 P 的力臂與力矩

1. 車體重力 $Mg$（順時針力矩，防止翻車）：
車體質心恰在前輪正上方，因此其重力作用線與後輪 P 的垂直水平距離為輪距 $a$：

$$\tau_{\text{順}} = Mg \times a$$

2. 均質支架重力 $\frac{M}{8}g$（逆時針力矩，造成翻車）：
支架為均勻材質，質心在其長度中點（距底端 $L/2$ 處），支架與鉛直線夾角為 $30^\circ$： $$\text{力臂 } d_1 = \frac{L}{2} \sin 30^\circ = \frac{L}{2} \times \frac{1}{2} = \frac{L}{4}$$ $$\tau_1 = \left(\frac{M}{8}g\right) \times \left(\frac{L}{4}\right) = \frac{MgL}{32}$$

3. 人員與工作台重力 $\frac{M}{4}g$（逆時針力矩，造成翻車）：
工作台位於支架最頂端（距底端 $L$ 處）： $$\text{力臂 } d_2 = L \sin 30^\circ = L \times \frac{1}{2} = \frac{L}{2}$$ $$\tau_2 = \left(\frac{M}{4}g\right) \times \left(\frac{L}{2}\right) = \frac{MgL}{8}$$

步驟 3

列出轉動平衡方程式 $\Sigma \tau_P = 0$

要使車體不至翻覆，順時針力矩必須大於或等於逆時針力矩：

$$\tau_{\text{順}} \ge \tau_1 + \tau_2$$ $$Mga \ge \frac{MgL}{32} + \frac{MgL}{8}$$

兩邊同除以 $Mg$： $$a \ge L \left(\frac{1}{32} + \frac{4}{32}\right) = L \times \frac{5}{32}$$ $$L \le \frac{32}{5}a = 6.4a$$

✅ 正確答案： 支架長度最大可為 $\mathbf{\frac{32}{5}a}$，本題應選 (B)。
👨‍🏫

名師點撥・審題陷阱提醒

歷屆考生在這一題最常犯的錯誤有兩個：
1. 誤把車體質心當作前後輪中點：題目特別強調「車體質心恰在前輪軸正上方」，因此力臂是整整的 $a$，而非 $a/2$（若是 $a/2$，答案就會誤選成 D 選項 $16a/5$）。
2. 支架質心力臂忘記減半：均勻支架的重量作用在中點，因此力臂是 $\frac{L}{2}\sin 30^\circ$ 而不是 $L\sin 30^\circ$！
只要看清題目文字、選對翻覆支點，力矩秒算無比輕鬆！
