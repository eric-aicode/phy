靜力平衡 48：斜傾木棒樞紐施力方向與夾角範圍

底端水平拉繩約束・力矩平衡求解繩張力・正切函數單調性嚴格證明夾角範圍

1 題目情境與物理圖解

如圖所示，有一木棒上端以樞紐固定於牆角，木棒中間懸掛一重物 $W$，且木棒下端以一水平細繩固定於右側垂直牆面。

設木棒與鉛直線之夾角為 $\theta$（$0^\circ < \theta < 90^\circ$）。若樞紐施予木棒之力 $F$ 的方向與鉛直線之夾角為 $\alpha$，則夾角 $\alpha$ 可能為下列何者？

📐 樞紐反作用力與力矩正交分解 tan α = (1/2) tan θ < tan θ ⇒ 0° < α < θ

2 自我檢測與即時核對

請依據轉動平衡與正切函數關係，選出夾角 $\alpha$ 的正確範圍：

A $\alpha = 0^\circ$
B $0^\circ < \alpha < \theta$
C $\alpha = \theta$
D $\theta < \alpha < 90^\circ$
E 皆有可能

3 完整觀念解析與推導過程

$$\sum \tau_O = 0 \implies W \cdot \left(\frac{1}{2}\ell \sin\theta\right) = T \cdot (\ell \cos\theta) \implies T = \frac{1}{2}W \tan\theta$$ $$\sum F_y = 0 \implies F\cos\alpha = W, \quad \sum F_x = 0 \implies F\sin\alpha = T$$ $$\tan\alpha = \frac{T}{W} = \frac{1}{2}\tan\theta < \tan\theta \implies 0^\circ < \alpha < \theta$$

步驟一：以樞紐 O 為轉軸求水平繩張力 T

木棒長度為 $\ell$，與鉛垂線夾角為 $\theta$。以木棒上端樞紐 $O$ 為支點：

  • 重物 $W$ 懸掛於木棒中點（距 $O$ 點 $\frac{1}{2}\ell$），鉛直向下之重力力臂為 $\frac{1}{2}\ell \sin\theta$，產生順時針力矩。
  • 木棒下端受水平細繩拉力 $T$ 向右拉，水平拉力之鉛直力臂為 $\ell \cos\theta$，產生逆時針力矩。
$$W \cdot \left(\frac{1}{2}\ell \sin\theta\right) = T \cdot (\ell \cos\theta)$$ $$T = \frac{1}{2}W \cdot \frac{\sin\theta}{\cos\theta} = \frac{1}{2}W \tan\theta$$

步驟二：分析樞紐反作用力 F 之正交分量

木棒處於合力平衡狀態，設樞紐施予木棒之力為 $F$，方向與鉛垂線夾角為 $\alpha$（向左上方傾斜）：

  • 鉛直合力平衡：樞紐力鉛直向上分量平衡重力 $W$： $$F\cos\alpha = W$$
  • 水平合力平衡：樞紐力水平向左分量平衡水平繩張力 $T$： $$F\sin\alpha = T$$

步驟三：正切函數嚴格單調遞增證明角度範圍

將兩分力方程式相除：

$$\tan\alpha = \frac{F\sin\alpha}{F\cos\alpha} = \frac{T}{W}$$

將步驟一所求得的 $T = \frac{1}{2}W\tan\theta$ 代入：

$$\tan\alpha = \frac{\frac{1}{2}W\tan\theta}{W} = \frac{1}{2}\tan\theta$$

因為木棒處於實際傾斜平衡，夾角滿足 $0^\circ < \theta < 90^\circ$。在第一象限內，正切函數 $\tan x$ 為嚴格遞增函數且恆為正：

$$0 < \tan\alpha = \frac{1}{2}\tan\theta < \tan\theta$$ $$\implies 0^\circ < \alpha < \theta$$

因此，夾角 $\alpha$ 的範圍必定介於 $0^\circ$ 與 $\theta$ 之間。正確選項為 (B)。
