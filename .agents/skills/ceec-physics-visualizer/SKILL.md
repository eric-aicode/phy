# CEEC 高中物理專業可視化題庫處理規範 (CEEC Physics Visualizer Skill)

本 Skill 旨在規範高中物理「靜力學（向量封閉三角形、彈簧、力矩、平衡、摩擦力）」及力學題目的視覺化排版、互動式圖解製作、解析條列標準與題目互連架構。

---

## 🎨 一、深色背景與向量線條色彩規範 (Dark Mode Vector Palette)

- **舞台底色**：深藍黑夜幕色調（`#070b14` ~ `#090d16`），避免刺眼反光。
- **線條禁用純黑**：嚴格禁止在深色背景使用 `#000000` / `#000` / `black`。
- **色彩意義對應表**：
  | 元素類型 | 色碼 (HEX) | 視覺效果 | 使用時機 |
  | :--- | :--- | :--- | :--- |
  | **坐標軸與標記** | `#cbd5e1` / `#94a3b8` | 亮銀色 / 霧銀色 | x-y 坐標軸、邊框、水平地面、天花板、斜線陰影 |
  | **主作用力 / 長度** | `#00e5ff` | 螢光青 (Cyan) | 主力向量 $\vec{F}_1$、繩張力 $T_1$、主要幾何長度 |
  | **次作用力 / 角度** | `#facc15` | 耀金黃 (Amber) | 次力向量 $\vec{F}_2$、彈簧彈力 $F_s$、角度 $\theta$、斜率標記 |
  | **垂直分量 / 短邊** | `#c084fc` | 紫羅蘭 (Violet) | 垂直向量 $\vec{F}_3$、垂直短邊、繩張力 $T_2$ |
  | **重力 / 荷載** | `#ff5252` | 珊瑚紅 (Red) | 鉛直重力 $W$、外力拉扯、危險/臨界標記 |
  | **合力 / 答案確認** | `#00e676` | 翡翠綠 (Green) | 合力向量 $\vec{R}$、平衡結果、正確選項與答案強調 |
  | **文字說明** | `#f1f5f9` | 純白銀 | SVG 內部所有標註文字、單位與數值 |

## 📐 二、漸進圖解與原圖並列切換 (Diagram Switcher & Side-by-Side)

每道題目必須設計清晰、放大的 SVG 圖形，並提供上方切換標籤：
1. **`📐 原始題圖`**：清晰展現題幹物理裝置、幾何外觀與已知角度。
2. **`💡 圖解受力分析 / 正交投影`**：標出隔離體受力向量、分解分量與角度投影。
3. **`🔺 向量封閉三角形 / 臨界圖解`**：將各力首尾相接，凸顯特殊角（$3:4:5$、$1:1:\sqrt{2}$、$1:\sqrt{3}:2$）或幾何比例。
4. **`⚖️ 原圖與圖解並列對照 (Side-by-Side)`**：將原題目圖與受力圖同屏並列，方便學生直接比對各力的著力點與來源。

---

## 🔍 三、動態縮放與推演功能 (Dynamic Zoom & Inspection)

- 圖解舞台右上角常設 **縮放工具列**：
  - `🔍+ 放大`（每次 $+15\%$）
  - `🔍- 縮小`（每次 $-15\%$）
  - `⟲ 重置`（恢復 $100\%$ 原比例）
- 支援 SVG 向量無損縮放，便於課堂講解、大螢幕投影或學生細看幾何交點。

---

## 📝 四、解析極簡條列原則 (Zero-Fluff Concise Solutions)

**嚴格禁止冗長敘述性廢話！** 學生容易卡在畫受力圖與幾何角度，解析必須圖解優先，文字僅限於骨幹條列：
- 📌 **【重點一・物理受力】**：寫出隔離體所受外力與平衡方程式（$\sum \vec{F} = 0$ 或 $\sum \tau = 0$）。
- 📐 **【重點二・幾何對應】**：指明直角三角形、邊長比或三角函數投影。
- ⚡ **【重點三・速解運算】**：一步代入數字，求得最終結果並框列答案。
- **公式規範**：所有除法與分數一律使用橫式分數（`\frac{a}{b}` 或 `\dfrac{a}{b}`），禁止斜線除號。

---

## 🔗 五、相似觀念關聯體系 (Related Similar Problems)

每一題均須分析其**核心物理模型**，並於題目卡片下方配置 **相似題速連標籤（Related Problem Chips）**：
- 模型分類標籤：例如 `雙繩懸吊平衡`、`斜面摩擦臨界`、`彈簧串並聯等效`、`力矩支點選擇` 等。
- 點擊相似題標籤可瞬間無縫跳轉至該題，形成觀念連貫的專題練習鏈。

---

## 🖥️ 六、三欄同屏佈局標準 (3-Column Layout Standard)

- **左欄（340~360px）**：📝 題目敘述、條件列表與相似題速連（固定釘選，字體舒適）。
- **中欄（420~520px）**：📐 核心物理圖解切換台（固定釘選！切換標籤、動態縮放、並列對照，隨解析捲動時絕不消失）。
- **右欄（自適應寬度）**：💡 多種解法重點解析（獨立流暢捲動，隨時能抬頭對照中欄圖解）。
