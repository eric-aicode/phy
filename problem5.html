範例 5：容器內雙球接觸正向力分析

圓形幾何連心線角度・隔離體法（A球封閉直角三角形）與整體法超速解

📖

題目內容

聯考與競賽高頻經典力學題

如圖所示，A、B 兩球均重 $W$，置於底邊寬度為 $3r$（$r$ 為 A、B 兩球之半徑）的光滑鉛直圓柱形（或槽狀）容器中。

若兩球表面及容器內壁皆光滑無摩擦，試求達靜力平衡時：

  • (1) 容器底作用於 B 球之正向力 $N_{\text{底}}$ 為？
  • (2) 容器壁對 B 球之正向力 $N_2$ 為？
  • (3) A、B 兩球之間的相互作用正向力 $N_{AB}$ 為？

💡 名師思考引導：

  1. 幾何角度秒殺：兩球圓心水平距離 $\Delta x = 3r - r - r = r$。連心線長度為兩半徑和 $r + r = 2r$。在直角三角形中，底邊 $r$，斜邊 $2r$，夾角必為 $\cos\alpha = \frac{r}{2r} = \frac{1}{2} \implies \alpha = 60^\circ$（連心線與水平夾角 $60^\circ$，與鉛直夾角 $30^\circ$）！
  2. 第 (1) 小題整體法：將 A 球與 B 球視為一個系統，鉛直方向只有向下總重力 $W + W = 2W$ 以及容器底部的正向力 $N_{\text{底}}$。因此 $N_{\text{底}} = 2W$ 一秒得解！
  3. 隔離 A 球受力分析：A 球受三力平衡：鉛直向下重力 $W$、右壁水平向左推力 $N_1$、B 球沿連心線向右上推力 $N_{AB}$。三力組成直角三角形： $$\sin 60^\circ = \frac{W}{N_{AB}} \implies N_{AB} = \frac{W}{\sin 60^\circ} = \frac{2\sqrt{3}}{3}W$$ $$\tan 60^\circ = \frac{W}{N_1} \implies N_1 = \frac{W}{\sqrt{3}} = \frac{\sqrt{3}}{3}W$$
  4. 第 (2) 小題水平平衡：整個系統水平方向只有左壁推力 $N_2$（向右）與右壁推力 $N_1$（向左），兩者必然大小相等：$N_2 = N_1 = \frac{\sqrt{3}}{3}W$！

完整圖解解析

幾何關係、整體法與隔離法三力平衡精解
幾何先行

雙球圓心幾何與角度確定

容器底寬 $3r$，兩球半徑皆為 $r$：
• B 球貼左壁，其圓心到左壁距離為 $r$。
• A 球貼右壁，其圓心到右壁距離為 $r$。
• 因此 A、B 兩球圓心的水平距離為：

$$\Delta x = 3r - r - r = r$$

又兩球外切，連心線長度為： $$O_A O_B = r + r = 2r$$ 設連心線與水平面的夾角為 $\alpha$： $$\cos \alpha = \frac{\Delta x}{O_A O_B} = \frac{r}{2r} = \frac{1}{2} \implies \alpha = \mathbf{60^\circ}$$ 即連心線與水平夾角為 $60^\circ$（與鉛垂線夾角為 $30^\circ$）。

第 (1) 小題

容器底作用於 B 球之正向力 $N_{\text{底}}$（系統整體法）

將 A 球與 B 球視為一個共同系統（整體法）：
系統在鉛直方向受到的外力僅有：
1. 兩球總重力向下：$W_{\text{總}} = W_A + W_B = 2W$
2. 容器底部向上的正向力：$N_{\text{底}}$

$$\Sigma F_y = 0 \implies N_{\text{底}} = W_A + W_B = \mathbf{2W}$$

（註：A、B 彼此間的正向力為系統內力，在整體法中自動抵消，無需計算！）

第 (3) 小題

A、B 相互作用力 $N_{AB}$（隔離 A 球與封閉直角三角形）

隔離上方 A 球，其受三個共點力達平衡：
• 鉛直向下之重力 $W$
• 右側容器壁水平向左之正向力 $N_1$
• B 球沿連心線方向向右上方之推力 $N_{AB}$（與水平夾 $60^\circ$）

三力首尾相接構成直角三角形（鉛直邊為 $W$，水平邊為 $N_1$，斜邊為 $N_{AB}$）：

$$\sin 60^\circ = \frac{W}{N_{AB}} \implies N_{AB} = \frac{W}{\sin 60^\circ} = \frac{W}{\frac{\sqrt{3}}{2}} = \mathbf{\frac{2\sqrt{3}}{3}W}$$
第 (2) 小題

容器壁對 B 之正向力 $N_2$

由 A 球的直角力三角形，水平底邊即為右壁推力 $N_1$：

$$\tan 60^\circ = \frac{W}{N_1} \implies N_1 = \frac{W}{\tan 60^\circ} = \frac{W}{\sqrt{3}} = \mathbf{\frac{\sqrt{3}}{3}W}$$

再對整體 (A + B) 分析水平方向外力平衡：
系統水平方向僅受左壁正向力 $N_2$（向右）與右壁正向力 $N_1$（向左）：

$$\Sigma F_x = 0 \implies N_2 = N_1 = \mathbf{\frac{\sqrt{3}}{3}W}$$
拉密定理

隔離 A 球利用拉密定理（Lami's Theorem）求連心力

分析 A 球受三共點力平衡：重力 $W$（向下）、右壁推力 $N_1$（向左）、B 對 A 推力 $N_{AB}$（指向右上，與水平夾 $60^\circ$）。
三力之間的夾角分別為：

  • $W$ 與 $N_1$ 之夾角：$90^\circ$
  • $W$ 與 $N_{AB}$ 之夾角：$180^\circ - 60^\circ = 120^\circ$
  • $N_1$ 與 $N_{AB}$ 之夾角：$90^\circ + 60^\circ = 150^\circ$

由拉密定理列式：

$$\frac{W}{\sin 150^\circ} = \frac{N_1}{\sin 120^\circ} = \frac{N_{AB}}{\sin 90^\circ}$$

代入各特殊角之正弦值 $\sin 150^\circ = \frac{1}{2}$，$\sin 120^\circ = \frac{\sqrt{3}}{2}$，$\sin 90^\circ = 1$：

$$N_{AB} = \frac{W \cdot \sin 90^\circ}{\sin 150^\circ} = \frac{W \cdot 1}{\frac{1}{2}} = 2W \quad \text{? 慎防夾角對應！}$$ $$\text{精確對應：} \frac{W}{\sin 120^\circ} = \frac{N_{AB}}{\sin 90^\circ} \implies N_{AB} = \frac{W}{\frac{\sqrt{3}}{2}} = \mathbf{\frac{2\sqrt{3}}{3}W}$$ $$\frac{N_1}{\sin 150^\circ} = \frac{W}{\sin 120^\circ} \implies N_1 = W \cdot \frac{\frac{1}{2}}{\frac{\sqrt{3}}{2}} = \mathbf{\frac{\sqrt{3}}{3}W}$$
底球正交分解

隔離 B 球正交分解求底面支持力 $N_{\text{底}}$ 與壁力 $N_2$

由牛頓第三運動定律，A 球對 B 球的作用力 $N_{BA} = N_{AB} = \frac{2\sqrt{3}}{3}W$，方向斜向左下，與水平夾 $60^\circ$。
B 球受 4 個力作用：

  • 水平方向：左壁推力 $N_2$（向右）與 $N_{BA}$ 水平分量（向左）平衡： $$\Sigma F_x = 0 \implies N_2 = N_{BA} \cos 60^\circ = \left(\frac{2\sqrt{3}}{3}W\right) \cdot \frac{1}{2} = \mathbf{\frac{\sqrt{3}}{3}W}$$
  • 鉛直方向：容器底支持力 $N_{\text{底}}$（向上）與 B球自重 $W$ 加上 $N_{BA}$ 鉛直分量（向下）平衡： $$\Sigma F_y = 0 \implies N_{\text{底}} = W + N_{BA} \sin 60^\circ = W + \left(\frac{2\sqrt{3}}{3}W\right) \cdot \frac{\sqrt{3}}{2} = W + W = \mathbf{2W}$$

與整體法結論完全吻合，印證隔離法與整體法的雙向自洽性！

✅ 最終標準解答：
(1) 容器底對 B 正向力：$N_{\text{底}} = \mathbf{2W}$
(2) 容器壁對 B 正向力：$N_2 = \mathbf{\frac{\sqrt{3}}{3}W}$
(3) A、B 相互作用正向力：$N_{AB} = \mathbf{\frac{2\sqrt{3}}{3}W}$

名師解題心法・接觸力問題的兩把寶刀

1. 第一把寶刀（整體法）：求外部支撐力（例如底面支持力、整體水平壁面力）時，把所有物體「綁在一起」當成一個大質點，內力瞬間消失，省時 80%！
2. 第二把寶刀（封閉直角三角形）：求接觸面的相互作用力時，隔離受力最單純的單一物體（本題為 A 球，只受三力且有兩力垂直），直接畫出 $30^\circ$-$60^\circ$-$90^\circ$ 直角三角形，答案秒出！
