相似三角形

幾何 $\triangle APO$ 與力封閉向量三角形相似

設大球球心為 $O$，懸掛點為 $A$，小球所在位置為 $P$：

  • 球心到小球距離為大球半徑：$\overline{OP} = R$。
  • 題目給定繩長等於大球半徑：$\overline{AP} = R$。
  • 因此幾何三角形 $\triangle APO$ 為等腰三角形，$\overline{AP} = \overline{OP} = R$。

小球受三力平衡：張力 $\vec{T} \parallel \overline{PA}$、正向力 $\vec{N} \parallel \overline{OP}$、重力 $\vec{W} \parallel \overline{AO}$。
三力首尾相接構成的向量三角形與幾何三角形 $\triangle APO$ 嚴格相似：

$$\frac{T}{\overline{AP}} = \frac{N}{\overline{OP}} = \frac{W}{\overline{AO}}$$ $$\text{因 } \overline{AP} = \overline{OP} \implies \mathbf{T = N}$$

又幾何底邊長為 $\overline{AO} = 2R\cos\theta$，直接代入比例式：

$$\frac{N}{R} = \frac{W}{2R\cos\theta} \implies \mathbf{N = \frac{W}{2\cos\theta}}$$
正交分解

沿鉛直與水平分量列平衡方程

繩張力 $\vec{T}$ 與正向力 $\vec{N}$ 分別與鉛直方向夾角為 $\theta$：

  • 水平方向平衡： $$\Sigma F_x = 0 \implies T\sin\theta = N\sin\theta \implies \mathbf{T = N}$$
  • 鉛直方向平衡： $$\Sigma F_y = 0 \implies T\cos\theta + N\cos\theta = W$$

將 $T = N$ 代入鉛直平衡式：

$$2N\cos\theta = W \implies \mathbf{N = \frac{W}{2\cos\theta}}$$
$$N = \frac{W}{2\cos\theta} \quad \text{（正確答案為 D）}$$
