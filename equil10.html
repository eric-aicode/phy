幾何邊角

利用封閉直角力三角形秒解五大選項

將小球所受三力首尾相接：鉛直向下重力 $\vec{W}$、水平向右擋板推力 $\vec{N}_2$、向左上方斜面正向力 $\vec{N}_1$。因 $\vec{W} \perp \vec{N}_2$，構成標準直角三角形：

  • 斜邊為 $N_1$，鄰邊為 $W$，頂角為 $\alpha$： $$\cos\alpha = \frac{W}{N_1} \implies N_1 = \frac{W}{\cos\alpha} = W\sec\alpha$$ 在 $0^\circ < \alpha < 90^\circ$ 區間內，$\cos\alpha < 1$，故直角三角形的斜邊 $N_1$ 必大於股長 $W$（$N_1 > W$ 恆成立，選項 A 正確）。
  • 對邊為 $N_2$，鄰邊為 $W$： $$\tan\alpha = \frac{N_2}{W} \implies N_2 = W\tan\alpha$$ 當 $\alpha < 45^\circ$ 時，$\tan\alpha < 1 \implies N_2 < W$；只有在 $\alpha > 45^\circ$ 時才有 $N_2 > W$。故選項 (B) 宣稱「一定大於 $W$」顯屬錯誤！
正交分解

水平鉛直獨立方程與函數單調性

取水平向右為 $+x$，鉛直向上為 $+y$：

  • 鉛直方向平衡： $$\Sigma F_y = 0 \implies N_1 \cos\alpha = W \implies N_1 = \frac{W}{\cos\alpha}$$
  • 水平方向平衡： $$\Sigma F_x = 0 \implies N_2 = N_1 \sin\alpha = \left(\frac{W}{\cos\alpha}\right)\sin\alpha = W\tan\alpha$$

單調性分析（當傾角 $\alpha$ 增大時）：

  1. $\alpha \uparrow \implies \cos\alpha \downarrow \implies N_1 = \frac{W}{\cos\alpha} \uparrow$（斜面正向力必然增大，選項 C 正確）。
  2. $\alpha \uparrow \implies \tan\alpha \uparrow \implies N_2 = W\tan\alpha \uparrow$（擋板抗力必然增大，選項 D 正確）。
  3. 接觸面光滑無摩擦，正向力方向恆沿法線垂直斜面（選項 E 正確）。
本題要求選出錯誤敘述，正確答案為 (B)
