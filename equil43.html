靜力平衡 43：小童沿木板等速下滑之牆面與地面力變化

等速運動合力為零・整體系統三力平衡・力矩遞減趨勢與向量和守恆

1 題目情境與物理圖解

如圖所示，取一均質木板一端靠於鉛直光滑牆面，另一端以樞紐固定於水平地面。

今若一小童自此木板高處等速滑下，下滑過程中木板保持固定且不變形。若此期間光滑牆對木板之作用力為 $X$，地面對木板之作用力為 $Y$。

則此兩力在小童之下滑過程中，如何變化？

📐 （木板+小童）系統受力與動態下滑趨勢 X + Y + W = 0 ⇒ 向量和 X + Y = -W 恆定

2 自我檢測與即時核對

請考慮小童等速滑下之物理特性與受力平衡，選出正確的選項：

A $X$ 量值漸大、$Y$ 量值漸小
B $X$ 量值漸大、$Y$ 量值漸大
C $X$ 量值漸小、$Y$ 量值漸大
D $Y$ 之方向與地面之夾角保持不變
E $X$ 與 $Y$ 的向量和保持不變

3 完整觀念解析與推導過程

$$\text{小童等速下滑 } \implies \vec{a} = 0 \implies \sum \vec{F}_{\text{系統}} = 0$$ $$\vec{X} + \vec{Y} + \vec{W} = 0 \implies \vec{X} + \vec{Y} = -\vec{W} \quad (\text{大小與方向皆恆定})$$ $$\sum \tau_A = 0 \implies X \text{ 漸減，} Y = \sqrt{X^2 + W^2} \text{ 亦漸減}$$

步驟一：整體系統法與向量和恆定性（直接得解）

將「木板 + 小童」視為一個整體力學系統。因為小童是「等速滑下」，其加速度 $\vec{a} = 0$。因此對整體系統而言，合外力必定恆等於零：

$$\sum \vec{F} = \vec{X} + \vec{Y} + \vec{W}_{\text{總}} = 0$$

移項可得：

$$\vec{X} + \vec{Y} = -\vec{W}_{\text{總}}$$

因為木板與小童的總重力 $\vec{W}_{\text{總}}$ 是量值恆定、方向鉛直向下的定向量，所以 $-\vec{W}_{\text{總}}$ 為向上且大小固定的定向量。因此，$\vec{X}$ 與 $\vec{Y}$ 的向量和在下滑全程保持不變！選項 (E) 正確。

步驟二：以轉軸 A 列力矩分析 $X$ 的量值變化趨勢

以地面樞紐 $A$ 點為轉軸，此時地面力 $Y$ 對 $A$ 的力矩為 0。

光滑垂直牆面之正向力 $X$ 水平向右，其對 $A$ 的力臂為木板頂端高度 $h$（維持不變）。

當小童沿木板向下滑動時，小童離轉軸 $A$ 的水平距離逐漸縮小，因此小童重力對轉軸 $A$ 產生的順時針力矩逐漸變小。

為維持合力矩為零（$X \cdot h = \tau_{\text{板重}} + \tau_{\text{童重}}$），牆壁力矩必須隨之變小，因力臂 $h$ 固定，故 $X$ 的量值漸小。

步驟三：分析 $Y$ 的量值與方向變化（排除 A、B、C、D）

由整體系統之正交平衡：

  • 水平平衡：$Y_x = X$。因為 $X$ 漸小，所以 $Y$ 的水平分量 $Y_x$ 漸小。
  • 鉛直平衡：$Y_y = W_{\text{總}}$。因為垂直牆面光滑無摩擦力，地面鉛直分力必須完全承擔總重力，故 $Y_y$ 維持不變。
  • 地面力量值：$Y = \sqrt{Y_x^2 + Y_y^2} = \sqrt{X^2 + W_{\text{總}}^2}$。因為 $X$ 漸小，故 $Y$ 的量值亦漸小（排除 A、B、C）。
  • 地面力方向夾角 $\phi$：$\tan\phi = \dfrac{Y_y}{Y_x} = \dfrac{W_{\text{總}}}{X}$。因為 $X$ 漸小，$\tan\phi$ 增大，即 $Y$ 與地面的仰角逐漸增大，並非保持不變（排除 D）。

綜合以上各點，唯一正確的選項為 (E)。
