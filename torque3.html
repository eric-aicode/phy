步驟一

計算兩質點之重力與力臂

設細桿長度為 $d$，中點 O 固定為支點，故各質點到支點 O 的桿長皆為 $\frac{d}{2}$。

  • 上端質點：質量為 $m$，向下重力為 $W_1 = mg$。
  • 下端質點：質量為 $2m$，向下重力為 $W_2 = 2mg$。
  • 力臂判定：因為重力方向鉛直向下，力臂為支點到鉛垂線的水平垂直距離，即 $\text{力臂 } d_{\perp} = \frac{d}{2} \sin \theta$。
步驟二

判定力矩方向並列式求合

以 O 點為參考轉軸：

  • 下端 $2m$ 產生的力矩：位於支點右側，重力向下，產生順時鐘力矩： $$\tau_1 = (2mg) \times \left(\frac{1}{2}d \sin \theta\right) = mgd \sin \theta \quad (\text{順時鐘 } \circlearrowright)$$
  • 上端 $m$ 產生的力矩：位於支點左側，重力向下，產生逆時鐘力矩： $$\tau_2 = (mg) \times \left(\frac{1}{2}d \sin \theta\right) = \frac{1}{2}mgd \sin \theta \quad (\text{逆時鐘 } \circlearrowleft)$$

兩力矩轉向相反，合力矩量值為順、逆相消： $$\tau_{\text{合}} = \tau_1 - \tau_2 = mgd \sin \theta - \frac{1}{2}mgd \sin \theta = \mathbf{\frac{1}{2}mgd \sin \theta}$$

結論

本題正解為 (B) $\frac{1}{2}mgd \sin \theta$。
這道 87 聯考試題考查基本功：先將質量乘 $g$ 化為重力，接著透過幾何角度取正弦求水平力臂，最後注意一順一逆相消即可輕鬆拿分！
