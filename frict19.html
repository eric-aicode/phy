講義 靜力學-37 斜面滑動極限與摩擦係數比 靜摩擦力・練習 19

靜摩擦力 19：平行斜面外力極值比推導

恰將上滑最大力 Fmax 與恰將下滑最小力 Fmin・摩擦力方向反轉與代數化簡

1 題目情境與物理圖解

在傾斜角為 $\theta$ 的粗糙面上置一物體會自行滑下，若以平行於斜面向上之力支持之，在物體得以平衡的範圍內，改變力的大小，發現最大值為最小值的 $n$ 倍（$n > 1$），則靜摩擦係數 $\mu$ 為？

2 即時作答與物理定律判斷

💡 核心物理觀念詳解

1. 物體受力分析：

物體受重力沿斜面下滑分力 $mg\sin\theta$，以及垂直斜面的正向力 $N = mg\cos\theta$。 最大靜摩擦力大小為： $$f_{s,\max} = \mu N = \mu mg\cos\theta$$

2. 恰將下滑（外力最小值 $F_{\min}$）：

當外力較小、物體恰要下滑時，最大靜摩擦力方向沿斜面向上協助支持物體： $$F_{\min} + f_{s,\max} = mg\sin\theta$$ $$F_{\min} = mg\sin\theta - \mu mg\cos\theta \quad \cdots \text{(式 1)}$$

3. 恰將上滑（外力最大值 $F_{\max}$）：

當外力增大至物體恰要向上滑動時，最大靜摩擦力方向沿斜面向下抵抗上滑： $$F_{\max} = mg\sin\theta + f_{s,\max}$$ $$F_{\max} = mg\sin\theta + \mu mg\cos\theta \quad \cdots \text{(式 2)}$$

4. 聯立求靜摩擦係數 $\mu$：

已知 $F_{\max} = n F_{\min}$，將式 2 除以式 1： $$\frac{F_{\max}}{F_{\min}} = \frac{mg\sin\theta + \mu mg\cos\theta}{mg\sin\theta - \mu mg\cos\theta} = n$$ 分子分母同除以 $mg\cos\theta$： $$\frac{\tan\theta + \mu}{\tan\theta - \mu} = n$$ 交叉相乘： $$\tan\theta + \mu = n\tan\theta - n\mu$$ $$(n + 1)\mu = (n - 1)\tan\theta$$ $$\mu = \frac{n - 1}{n + 1}\tan\theta$$ 故正確答案為 (C)。
