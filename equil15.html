靜力平衡 15：均勻懸繩最低點張力與長度比

最低點水平切線特性・左右兩段分別隔離分析・均勻繩重與長度正比對應

題目內容

聯考與競賽高頻懸鏈模型

均勻之粗繩懸掛在兩鉛直牆壁間而成平衡，如圖所示。若繩的兩端 $A$、$B$ 點處繩之切線與鉛直線夾角分別為 $53^\circ$ 及 $37^\circ$，總繩重為 $W$。則：
(1) 繩最低點 $C$ 處之張力量值為多少？
(2) $AC$ 之長度與 $BC$ 之長度比為何？

依據受力平衡分析，最低點張力 $T_C$ 及兩段長度比 $AC : BC$ 分別為何？

A
$T_C = \frac{12}{25}W,\quad AC : BC = 9 : 16$
B
$T_C = \frac{12}{25}W,\quad AC : BC = 3 : 4$
C
$T_C = \frac{7}{12}W,\quad AC : BC = 9 : 16$
D
$T_C = \frac{5}{12}W,\quad AC : BC = 16 : 9$

$T_C = \frac{25}{12}W,\quad AC : BC = 3 : 4$

關鍵概念

懸鏈線最低點之水平切線特性

柔軟粗繩平衡時，在任一點的繩張力方向皆沿該點切線方向。
在繩的最低點 $C$ 處，切線必呈水平方向，因此該處張力 $T_C$ 純為水平向，無鉛直分量！
此特性是求解懸繩平衡的核心切入點。

步驟 1

分別隔離左段 $AC$ 與右段 $BC$ 分析

隔離左段 AC

設 $AC$ 段繩重為 $W_1$。
受到三個力作用：

  • 最低點 $C$ 之水平向右張力 $T_C$
  • 重力 $W_1$（鉛直向下）
  • $A$ 點繩張力 $T_A$（與鉛直夾角 $53^\circ$）
由三力平衡之直角力三角形： $$\tan 53^\circ = \frac{T_C}{W_1} \implies \frac{4}{3} = \frac{T_C}{W_1} \implies W_1 = \frac{3}{4}T_C$$

隔離右段 BC

設 $BC$ 段繩重為 $W_2$。
受到三個力作用：

  • 最低點 $C$ 之水平向左張力 $T_C$
  • 重力 $W_2$（鉛直向下）
  • $B$ 點繩張力 $T_B$（與鉛直夾角 $37^\circ$）
由三力平衡之直角力三角形： $$\tan 37^\circ = \frac{T_C}{W_2} \implies \frac{3}{4} = \frac{T_C}{W_2} \implies W_2 = \frac{4}{3}T_C$$

步驟 2

計算最低點張力 $T_C$

整條粗繩總重為 $W = W_1 + W_2$： $$W = \frac{3}{4}T_C + \frac{4}{3}T_C = \left(\frac{9 + 16}{12}\right)T_C = \frac{25}{12}T_C$$ 移項即得最低點張力： $$T_C = \frac{12}{25}W$$

步驟 3

計算兩段長度比 $AC : BC$

因繩為質地均勻之粗繩，繩之重量與長度成正比： $$\frac{AC \text{ 長度}}{BC \text{ 長度}} = \frac{W_1}{W_2} = \frac{\frac{3}{4}T_C}{\frac{4}{3}T_C} = \frac{3/4}{4/3} = \frac{9}{16}$$

結論： 本題正確答案為 (A) $T_C = \frac{12}{25}W,\quad AC : BC = 9 : 16$。
