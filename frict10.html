靜摩擦力 10：等加速滑動與動摩擦係數計算

位移時間求解加速度・牛頓第二定律合力關係・動摩擦係數反推求解

1 題目情境與物理圖解

在水平桌面上，質量為 $2.0\text{ kg}$ 的靜止木塊，受 $3\text{ N}$ 之水平拉力作用，在 $4.0\text{ 秒}$ 內移動了 $8.0\text{ m}$。假設重力加速度 $g = 10\text{ m/s}^2$，則木塊與桌面間之動摩擦係數 $\mu_k$ 為多少？

動力滑行力學模型 s = 1/2 a t² ⟹ a = 1.0 m/s²，F - fk = ma ⟹ fk = 1.0 N

2 自我檢測與觀念選擇

由運動學公式求出木塊加速度後，再由牛頓第二定律推導，木塊與桌面間之動摩擦係數 $\mu_k$ 為何？

詳盡解析與物理思維

步驟一：由運動學計算等加速度

木塊初速度 $v_0 = 0$，在時間 $t = 4.0\text{ s}$ 內移動距離 $s = 8.0\text{ m}$：

$$s = v_0 t + \frac{1}{2} a t^2$$ $$8.0 = 0 + \frac{1}{2} a (4.0)^2 = 8a \implies a = 1.0\text{ m/s}^2$$

步驟二：由牛頓第二定律分析受力

木塊在水平方向受到水平拉力 $F = 3\text{ N}$ 與動摩擦力 $f_k$：

$$F_{\text{合}} = F - f_k = ma$$ $$3 - f_k = 2.0 \times 1.0 = 2.0\text{ N}$$ $$f_k = 3 - 2 = 1.0\text{ N}$$

步驟三：計算動摩擦係數 $\mu_k$

木塊在鉛直方向平衡，正向力 $N = mg = 2.0 \times 10 = 20\text{ N}$：

$$f_k = \mu_k N$$ $$1.0 = \mu_k \times 20 \implies \mu_k = \frac{1.0}{20} = 0.05$$
名師核心點撥：
本題是「運動學＋牛頓第二定律＋動摩擦力」的跨章節經典整合題！解題關鍵在於先由運動軌跡求出加速度 $a = 1.0\text{ m/s}^2$，再求合力 $ma = 2\text{ N}$，進而反推動摩擦力為 $1\text{ N}$，最後除以正向力 $20\text{ N}$ 得到 $\mu_k = 0.05$。答案為 (C)。
