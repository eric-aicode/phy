靜摩擦力 14：物體下滑與斜面維持靜止條件

4kg 光滑斜面・5kg 物體下滑・正向反作用力水平分量與地面最大靜摩擦力

1 題目情境與物理圖解

有一質量 $4\text{ 公斤}$，斜角 $37^\circ$ 的光滑斜面三角形木塊，其上放置質量 $5\text{ 公斤}$ 的物體，如圖所示。

若物體沿光滑斜面下滑，欲使木塊保持靜止，則三角形木塊底面與地面間的靜摩擦係數 $\mu_s$ 至少應為多少？（設重力加速度 $g = 10\text{ m/s}^2$）

2 即時作答與力學推導

💡 核心物理觀念詳解

1. 物體受力與斜面正向力：

物體質量 $m = 5\text{ kg}$，重力 $mg = 50\text{ N}$。 在光滑斜面上下滑時，物體受到垂直於斜面的正向支撐力： $$N_1 = mg\cos 37^\circ = 50 \times \frac{4}{5} = 40\text{ N}$$

2. 斜面受到物體之正向反作用力分解：

物體對斜面施加垂直於斜面向下的壓力 $N_1 = 40\text{ N}$。 將其分解至水平與鉛直方向：

  • 水平向右推力： $$F_x = N_1 \sin 37^\circ = mg\cos 37^\circ \sin 37^\circ = 40 \times \frac{3}{5} = 24\text{ N}$$
  • 鉛直向下壓力： $$F_y = N_1 \cos 37^\circ = mg\cos^2 37^\circ = 40 \times \frac{4}{5} = 32\text{ N}$$

3. 斜面平衡與地面正向力：

斜面本身質量 $M = 4\text{ kg}$，重力 $Mg = 40\text{ N}$。 斜面在鉛直方向受力平衡： $$N_{\text{地}} = Mg + F_y = 40 + 32 = 72\text{ N}$$ 斜面在水平方向維持靜止，受地面的靜摩擦力 $f$ 平衡： $$f = F_x = 24\text{ N}$$

4. 臨界靜摩擦係數 $\mu_s$：

木塊不滑動之條件為水平靜摩擦力不超過最大靜摩擦力： $$f \le f_{s,\max} = \mu_s N_{\text{地}}$$ $$24 \le \mu_s \times 72 \implies \mu_s \ge \frac{24}{72} = \frac{1}{3}$$ 故靜摩擦係數至少應為 $1/3$，正確答案為 (C)。
