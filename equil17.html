靜力平衡 17：半球形碗內雙球平衡作用力

球心與碗心幾何關係・等邊正三角形構成・正交平衡推導球間互推力與碗壁支持力

📖

題目內容

聯考與競賽碗內置球經典題

如圖所示，光滑半球形碗之內半徑為 $3r$。碗內水平放置兩個半徑均為 $r$、重量均為 $W$ 之相同小球。
當兩球在碗底呈靜止平衡時，試求：
(1) 兩球之間的相互作用力量值為何？
(2) 球對碗壁之作用力量值為何？

🧭 解法一【向量平移】：左圖「共點力」如何變成右圖「封閉三角形」？
• 左圖（共點力）：三個力起點都在球心 $B$，分別為 W (向下 ↓)、X (向右 →)、Y (向左上 ↖)。
• 平移步驟（首尾相接）：從起點畫 W(↓)，從其箭頭接續畫 X(→)，再從 X 箭頭接續畫 Y(↖)。
• 閉合回到起點：三個箭頭首尾相接剛好繞一圈封閉回到出發點，代表合力為零 $\Sigma \vec{F} = \vec{0}$，直角三角形邊長比直接為 $1 : \sqrt{3} : 2$！
🎯 解法二【拉密定理】：三力共點平衡，各力與其「對角正弦」成正比！
• 三力夾角判定：水平向右與鉛直向下夾 90°；碗壁力向左上夾 120°（與水平）及 150°（與鉛直）。
• 力與對角配對（看對面）： $$\frac{W}{\sin 120^\circ} = \frac{X}{\sin 150^\circ} = \frac{Y}{\sin 90^\circ}$$
• 秒殺求值： $$\frac{W}{\frac{\sqrt{3}}{2}} = \frac{X}{\frac{1}{2}} = \frac{Y}{1} \implies \mathbf{X = \frac{W}{\sqrt{3}} = \frac{\sqrt{3}}{3}W} \quad , \quad \mathbf{Y = \frac{2W}{\sqrt{3}} = \frac{2\sqrt{3}}{3}W}$$

依據平衡受力推導，二球間相互作用力 $X$ 及球對碗壁作用力 $Y$ 分別為何？

A
二球間：$\frac{W}{\sqrt{3}}$，球對碗壁：$\frac{2W}{\sqrt{3}}$
B
二球間：$\frac{2W}{\sqrt{3}}$，球對碗壁：$\frac{W}{\sqrt{3}}$
C
二球間：$\frac{W}{2}$，球對碗壁：$\sqrt{3}W$
D
二球間：$\frac{\sqrt{3}W}{2}$，球對碗壁：$W$
E
二球間：$W$，球對碗壁：$2W$

步驟 1

球心幾何連線分析（正三角形性質）

設碗心為 $O$，兩小球球心分別為 $A$ 與 $B$：

  • 碗的內半徑為 $3r$，小球半徑為 $r$。
  • 碗心 $O$ 到各小球球心之距離為： $$OA = OB = 3r - r = 2r$$
  • 兩小球相互接觸，兩球心間之距離為： $$AB = r + r = 2r$$

因此 $\triangle OAB$ 之三邊長均為 $2r$，為一正三角形！
由對稱性，通過 $O$ 與兩球切點的鉛垂線平分頂角： $$\angle AOB = 60^\circ \implies \text{各球心連線 } OA、OB \text{ 與鉛直線夾角均為 } 30^\circ$$

步驟 2

隔離右球（B 球）受力分析

$B$ 球處於靜止平衡，共受三個共點力作用：

  • 重力 $W$：鉛直向下。
  • 碗壁正向支持力 $Y$：沿法線方向通過碗心 $O$ 與球心 $B$，方向斜向左上，與鉛垂線夾角為 $30^\circ$。
  • 左球 $A$ 對 $B$ 之推力 $X$：水平向右。
步驟 3

列平衡方程式求解（兩種解法對照）

【方法一：直角三角形幾何邊長比】

由向量閉合三角形，邊長比例為 $1 : \sqrt{3} : 2$： $$\frac{X}{W} = \tan 30^\circ = \frac{1}{\sqrt{3}} \implies X = \frac{W}{\sqrt{3}} = \frac{\sqrt{3}}{3}W$$ $$\frac{Y}{W} = \frac{1}{\cos 30^\circ} = \frac{2}{\sqrt{3}} \implies Y = \frac{2W}{\sqrt{3}} = \frac{2\sqrt{3}}{3}W$$

【方法二：拉密定理（Lami's Theorem）】

三力共點平衡時，每一力與另外兩力夾角的正弦成正比： $$\frac{W}{\sin 120^\circ} = \frac{X}{\sin 150^\circ} = \frac{Y}{\sin 90^\circ}$$ 代入正弦函數特殊角數值： $$\frac{W}{\frac{\sqrt{3}}{2}} = \frac{X}{\frac{1}{2}} = \frac{Y}{1}$$ $$\implies X = \frac{W \cdot \frac{1}{2}}{\frac{\sqrt{3}}{2}} = \frac{W}{\sqrt{3}}, \qquad Y = \frac{W \cdot 1}{\frac{\sqrt{3}}{2}} = \frac{2W}{\sqrt{3}}$$ 兩種方法推導結果完全一致！

結論： 本題正確答案為 (A) 二球間作用力 $\frac{W}{\sqrt{3}}$，球對碗壁作用力 $\frac{2W}{\sqrt{3}}$。
