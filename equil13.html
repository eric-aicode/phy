靜力平衡 13：斜面雙外力平衡與正向力

平行拉力與水平推力共同作用・三角方程求解傾角・向量封閉四邊形全等對稱

題目內容

經典斜面力學綜合題

重 $2W$ 之物體，置於光滑斜面上。同時施一平行於斜面向上之拉力 $W$，以及一水平向右方向之推力 $W$，恰使物體靜止不動。則斜面作用在物體的正向力為多少 $W$？

請問斜面作用在物體上的正向力為多少倍的 $W$？

A
$1\,W$
B
$\sqrt{2}\,W$
C
$\frac{3}{2}\,W$
D
$2\,W$
E
$\frac{5}{2}\,W$

核心解析與詳細推導

方法一

正規正交分解法（沿斜面與垂直斜面）

設斜面傾角為 $\theta$。將各力沿「平行斜面」與「垂直斜面」兩互相垂直方向進行分解：

  • 重力 $2W$：平行斜面向下分力為 $2W\sin\theta$；垂直斜面向下分力為 $2W\cos\theta$。
  • 平行拉力 $W$：沿斜面向上，大小為 $W$。
  • 水平推力 $W$：平行斜面向上分力為 $W\cos\theta$；垂直斜面向下壓分力為 $W\sin\theta$。
  • 斜面正向力 $N$：垂直斜面向上。
1. 平行斜面方向合力為零：

$$W + W\cos\theta = 2W\sin\theta \implies 1 + \cos\theta = 2\sin\theta$$ 將兩邊同時平方，利用 $\sin^2\theta = 1 - \cos^2\theta$： $$(1+\cos\theta)^2 = 4\sin^2\theta = 4(1 - \cos^2\theta)$$ $$1 + 2\cos\theta + \cos^2\theta = 4 - 4\cos^2\theta$$ $$5\cos^2\theta + 2\cos\theta - 3 = 0$$ 因式分解： $$(5\cos\theta - 3)(\cos\theta + 1) = 0$$ 因 $0^\circ < \theta < 90^\circ$，$\cos\theta \neq -1$，解得： $$\cos\theta = \frac{3}{5} \implies \sin\theta = \frac{4}{5} \quad (\theta = 53^\circ)$$

2. 垂直斜面方向合力為零求正向力 $N$：

斜面正向力平衡物體的垂直斜面重力分量與水平推力之壓入分量： $$N = 2W\cos\theta + W\sin\theta$$ 代入 $\cos\theta = \frac{3}{5}$ 與 $\sin\theta = \frac{4}{5}$： $$N = 2W\left(\frac{3}{5}\right) + W\left(\frac{4}{5}\right) = \frac{6}{5}W + \frac{4}{5}W = \frac{10}{5}W = 2W$$

方法二

進階速解：向量閉合四邊形之幾何全等

物體在四力作用下靜止平衡，其四個力向量首尾相接必構成一個封閉四邊形：

  • 重力向量長度為 $2W$（鉛直向下）。
  • 水平推力長度為 $W$（水平向右）。
  • 平行拉力長度為 $W$（沿斜面向上）。
  • 斜面正向力 $N$ 垂直於斜面，首尾相接回到起點。

觀察四邊形兩邊均為 $W$，且正向力垂直於拉力。連結對角線可將四邊形分割成兩對稱的直角三角形，由全等幾何性質，斜邊與對應邊長立即可得： $$N = 2W$$ 無需複雜計算，幾何直觀一目了然！

結論： 本題正確答案為 (D) $2W$。
